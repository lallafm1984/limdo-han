# LimDo 자동차 이미지 자산 계약

## 목적

글을 읽지 못하지만 한국어를 들을 수 있고 자동차를 좋아하는 다섯 살 아이가 쓰기 방향과 성공 보상을 모양과 움직임만으로 이해하도록 돕는다. 이 자산은 동물 안내를 대체하는 자동차 안내와 글자별 실제 획수 이동 보상에 사용한다.

## 공통 생성 프롬프트

Codex 내장 이미지 생성으로 다음 공통 조건을 사용했다.

> Android 유아용 한글 쓰기 앱에 쓰는 친근한 자동차 한 대를 만든다. 오른쪽을 향한 측면 3/4 구도, 둥근 차체, 굵고 일정한 어두운 외곽선, 밝고 선명한 색, 큰 앞유리 눈과 웃는 앞모습, 윤기 있는 2D 그림체를 사용한다. 다섯 살 아이가 작은 크기에서도 차종을 구별할 수 있어야 한다. 사람·운전자·배경·지면 그림자·글자·번호·브랜드·상표·워터마크를 넣지 않는다. 차량 전체를 자르지 않고 중앙에 두며 바깥은 실제 투명 알파로 만든다.

차종별 차이는 다음으로 제한했다.

- 경찰차: 파랑·흰색 차체와 빨강·파랑 경광등
- 소방차: 빨간 차체, 짧은 은색 사다리와 파란 경광등
- 구급차: 흰색·민트색 차체, 파란 경광등과 빨간 하트
- 스포츠카: 낮고 둥근 노랑 차체와 주황 강조색
- 택시: 노랑 차체, 글자 없는 체크 띠와 빈 지붕 표시등
- 버스: 하늘색·크림색 차체와 큰 옆창 세 개
- 쓰레기차: 밝은 초록 차체, 깨끗한 수거함과 화살표 재활용 표식
- 화물트럭: 주황 운전석과 청록색 닫힌 화물칸
- 지게차: 노랑·주황 차체, 오른쪽을 향한 낮은 포크와 둥근 보호대

모든 초안에서 배경 분리 전용 편집을 추가 실행했고, 최종본은 바깥 모서리 네 곳의 알파가 모두 `0.000`인지 검사했다.

## 적용 규칙

- 경찰차를 첫 기본 안내차로 사용한다.
- 지우기나 재시도만으로 현재 차량을 바꾸지 않는다.
- 차량은 예측 가능한 순서로 순환하고 같은 성공 callback에서 두 번 이동하지 않는다.
- 정답이면 lesson의 실제 `strokeCount`만큼 한 칸씩 이동한다. 현재 `ㄱ`은 1획이므로 1칸만 이동한다.
- 실패, 지우기, 다시 듣기는 차량을 이동시키지 않는다.
- 자동차와 이동 경로는 글자 guide·시작점·동적 방향 안내·끝점·아이 획을 가리지 않는다.
- 실제 앱 화면에 적용한 뒤 정확한 2340 × 1080에서 크기, 선명도, 투명 가장자리, 가림, 이동 횟수를 다시 검증한다.

## 검증 경계

이 문서의 자산 생성과 알파 검사는 실제 아이 관찰이 아니다. 앱 적용 뒤에도 자동 QA와 아이 대리 QA를 실제 아이 관찰과 구분한다.
