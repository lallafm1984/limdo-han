# LimDo 실제 5세 아이 관찰 계획과 기록 양식

## 현재 상태

- 실제 아이 관찰: 실행 안 함
- 이 문서는 관찰을 시작하기 전 준비물이다. 빈 양식과 판정 기준만 제공하며 관찰 결과를 대신하지 않는다.
- 자동 테스트, 에뮬레이터 확인, 성인 점검, 아이 대리 QA를 실제 아이 관찰로 기록하지 않는다.

## 목적과 대상

LimDo의 큰 쓰기판, 한국어 음성, 움직이는 획 안내, 조작 버튼, 자동차 보상이 한글 문장을 읽지 못하지만 한국어를 들을 수 있는 5세 아이에게 이해되고 편안한지 확인한다. 한 아이의 관찰은 해당 아이를 위한 제품 개선 근거이며 다른 아이 전체에 일반화하지 않는다.

## 보호자 동의와 안전

1. 보호자에게 관찰 목적, 예상 시간, 기록 항목, 언제든 중단할 수 있음을 설명하고 동의를 받는다.
2. 이름 대신 관찰 코드만 사용한다. 계정, 연락처, 얼굴, 목소리 등 식별 정보는 기본적으로 수집하지 않는다.
3. 화면 녹화·사진·음성 녹음은 보호자가 별도로 명시적으로 동의한 경우에만 사용하고, 보관 위치와 삭제 시점을 기록한다.
4. 아이가 싫다고 말하거나 기기를 밀어냄, 울음, 반복적인 회피, 피로·불안·짜증이 보이면 즉시 중단한다. 완료를 설득하거나 보상을 조건으로 계속시키지 않는다.
5. 총 관찰은 10분 이내, 한 과제는 2분 이내로 하고 아이가 원하면 언제든 쉬거나 끝낸다.

## 준비 조건

- 목표 Android 기기 또는 2340 × 1080과 동등한 화면에서 최신 검증 APK를 사용한다.
- 한국어 오프라인 음성의 재생 여부와 음량을 보호자가 먼저 확인한다.
- 알림과 방해 요소를 끄고 아이가 평소 기기를 사용하는 자세와 손으로 진행한다.
- 관찰자는 첫 시도 전에 버튼 이름이나 정답 획을 읽어 주지 않는다. 앱 음성과 움직임만 먼저 제공한다.
- 막혔을 때는 `화면에서 해보고 싶은 것을 눌러봐` 같은 중립 문장만 한 번 사용할 수 있으며, 사용 여부를 기록한다.

## 관찰 과제

각 과제는 아이가 원할 때만 진행한다. 순서를 바꾸거나 일부만 수행해도 된다.

1. 앱을 보여 주고 아무 설명 없이 첫 음성과 움직임을 본 뒤 쓰기를 시작하는지 관찰한다.
2. 초록 시작점에서 움직이는 화살표 방향으로 한 글자를 따라 쓰는지 관찰한다.
3. 일부러 선을 벗어나도록 유도하지 말고 자연스러운 실패가 생기면 음성·표식만으로 다시 시도하는지 관찰한다.
4. 아이가 스스로 다시 듣기와 지우기를 찾을 수 있는지 관찰한다. 요청하지 않으면 강제로 시키지 않는다.
5. 성공 뒤 자동차 이동과 성공 표식을 보고 다음 활동으로 넘어가는 방법을 찾는지 관찰한다.
6. 여러 글자 수업이 있을 때 음성과 모양이 바뀐 것을 알아차리고 같은 방식으로 새 글자를 시작하는지 관찰한다.

## 핵심 검증 기준

| 항목 | 통과 | 주의 | 실패 |
| --- | --- | --- | --- |
| 시작 이해 | 첫 음성·시범 뒤 도움 없이 10초 안에 초록점 또는 쓰기판을 터치함 | 중립 안내 1회 뒤 시작함 | 정답 위치·버튼을 직접 알려줘야 시작함 |
| 읽기 비의존 | 글자 문장을 읽어 주지 않아도 핵심 흐름을 진행함 | 한 단계에서 중립 안내 1회가 필요함 | 버튼 글자를 읽어 줘야만 진행함 |
| 입력 편안함 | 평소 손가락 움직임으로 획을 그리고 판정 통로를 반복해서 벗어나지 않음 | 한 획에서 손을 다시 놓거나 자세를 바꿈 | 입력 영역·획 굵기 때문에 반복 실패하거나 손 움직임을 과도하게 줄임 |
| 획순·방향 | 현재 초록점과 움직이는 화살표를 따라 시작·방향을 선택함 | 한 획에서 멈춘 뒤 시범을 다시 봄 | 다른 시작점·반대 방향을 반복함 |
| 실패 회복 | 실패 음성·↻ 뒤 스스로 재시도함 | 중립 안내 1회 뒤 재시도함 | 실패 의미를 몰라 활동을 중단함 |
| 조작 | 아이콘·위치로 다시 듣기·지우기·다음을 구분함 | 한 버튼에 중립 안내가 필요함 | 글자를 읽어 주거나 손을 이끌어야 구분함 |
| 보상 연결 | 성공 직후 자동차 이동을 보고 결과로 인식하며 다음으로 이동함 | 보상은 보지만 다음을 찾는 데 도움 1회가 필요함 | 자동차·성공 표식이 글자나 다음 행동을 방해함 |

통과 시간은 속도 경쟁을 위한 점수가 아니라 장시간 멈춤을 구분하는 관찰 기준이다. 아이가 천천히 하기를 선택하면 실패로 판정하지 않고 그 사실을 적는다.

## 문제 우선순위

- P0 즉시 중단: 안전, 공포, 심한 좌절, 개인정보 노출, 앱이 입력을 통제할 수 없는 상태.
- P1 독립 사용 차단: 읽어 주거나 손을 이끌지 않으면 시작·쓰기·재시도·다음 중 하나를 할 수 없음.
- P2 반복 불편: 독립 수행은 가능하지만 잘못 누름, 가림, 작은 표시, 음성·움직임 불일치, 불필요한 기다림이 반복됨.
- 같은 원인이 확인되지 않은 여러 행동을 하나의 결함으로 묶지 않는다. 수정 후보는 관찰 사실과 재현 조건이 있는 항목만 만든다.

## 제품 수정으로 전환하는 기준

1. P0는 즉시 작업을 중단하고 해당 흐름을 비활성화하거나 안전 조치를 우선한다.
2. P1은 하나의 재현 가능한 원인으로 좁혀 다음 결함 수정 루프의 최우선 후보로 기록한다.
3. P2는 같은 아이에게 반복되거나 자동·에뮬레이터 근거로 원인이 확인될 때 좁은 수정 루프로 만든다.
4. 선호 표현 하나만으로 UI를 전면 변경하지 않는다. 행동 사실, 발화, 재현 조건을 함께 남긴다.
5. 실제 관찰을 하지 않았거나 양식이 비어 있으면 결과는 계속 `실제 아이 관찰: 실행 안 함`이다.
