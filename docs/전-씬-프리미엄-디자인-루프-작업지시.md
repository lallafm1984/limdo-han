# 전 씬 프리미엄 디자인 루프 작업 지시

## 지시 목적

LimDo의 현재 기능과 교육 geometry는 유지하면서 홈부터 보호자 화면과 학습 완료까지 실제 사용자가 방문하는 모든 씬을 하나의 프리미엄 제품으로 보이게 다시 설계한다. 단색 배경, 반복 카드, 과도한 빈 공간, 화면별 화풍 단절을 없애고, 아이가 글을 읽지 않아도 다음 행동을 이해할 수 있는 배치·자산·파티클·모션·상태 피드백을 production에 적용한다.

이 문서는 한 번에 전 화면을 크게 뒤엎으라는 지시가 아니다. 자동 역할들이 같은 기준으로 독립 판정하고, 한 루프에서 하나의 공통 근본 원인 또는 한 화면군만 바꾸며, 모든 대상 씬이 최종 전체 플레이 관문을 통과할 때까지 다음 루프로 자동 전환하기 위한 지속 계약이다.

## 자동 역할 편성

다음 역할은 실제 사람 팀이 아니라 서로 다른 책임을 맡는 자동 검토 역할이다. 한 역할의 통과를 다른 역할의 통과로 대신하지 않는다.

1. 자동 아트 디렉션 역할: 브랜드 세계관, palette, 재질, 광원, 모서리, 그림자, 캐릭터, 배경 밀도와 화면 간 일관성을 판정한다.
2. 자동 UI/UX 역할: 아이와 보호자의 정보 위계, 5초 안의 다음 행동 발견, 터치 크기, 가림, 빈 공간, 오류 복구와 destructive action 안전성을 판정한다.
3. 자동 그래픽 자산 역할: 필요한 슬롯을 먼저 측정하고 `imagegen`의 Codex 내장 생성기로 bitmap을 만든 뒤 RGBA·alpha·bbox·halo·APK 포함·production 소비를 판정한다.
4. 자동 모션·VFX 역할: 진입·선택·조립·재시도·성공·완료의 시작·중간·끝, 파티클 밀도, 입력 비가림과 움직임 줄이기를 판정한다.
5. 자동 Android 성능 역할: bitmap decode 예산, 프레임 안정성, lifecycle 정리, 메모리 증가, APK 크기와 minSdk 26 동작을 판정한다.
6. 자동 접근성·아이 대리 QA 역할: 글을 읽지 못하지만 한국어를 들을 수 있는 다섯 살 아이 관점과 TalkBack·font scale·대비를 판정한다. 실제 아이 관찰이라고 표현하지 않는다.
7. 자동 최종 QA 역할: 구현 역할과 독립적으로 모든 고유 씬·상태·callback·navigation·회귀 행렬을 새 최종 APK에서 판정한다.

## 현재 감사 결론

### 유지할 강점

- 홈의 세 주 메뉴 touch bounds 약 688 × 702 px를 줄이지 않는다.
- 쓰기 내부 1962 × 954 px와 네 조작 168 × 168 px를 줄이지 않는다.
- 현재 교육용 한글 geometry, 표시·판정 공유, 획순, 시작·끝 표식과 자유 쓰기 흐름을 디자인을 이유로 바꾸지 않는다.
- 성공 화면의 부드러운 3D toy/clay 그림체와 action atlas의 촉각적인 아이콘은 새 화풍의 품질 기준으로 활용할 수 있다.
- 보호자 화면의 비스크롤 분류 그리드와 명시적 페이지 버튼 계약을 유지한다.

### 해결할 근본 원인

- 홈과 선택 화면은 단색 면과 반복 카드가 화면의 거의 전부라 브랜드·공간감·탐험 기대가 없다.
- 쓰기·성공 화면만 raster와 3D 재질이 있고 나머지는 평면 UI라 한 앱처럼 이어지지 않는다.
- 보호자 overview는 탭·상태·카드가 경쟁하고 작은 보조 문구가 있으며, 녹음 화면은 반대로 같은 상태를 반복하면서 중앙이 과도하게 빈다.
- 메뉴 전환은 글자 확대·fade만 있어 앞뒤 장면을 연결하지 못한다.
- 학습 완료는 현재 가장 중요한 종료 보상에 비해 시각적 보상이 빈약하다.
- `GaAssembly`는 render·back 분기는 남아 있지만 production navigation에서 진입시키는 call site가 없다. 사용자가 다시 노출하라고 지시하기 전에는 도달 가능한 씬으로 계산하거나 디자인 비용을 쓰지 않는다.
- 실제 production 참조 raster는 action atlas, sunny background, success feedback 중심이다. 별도 gecko와 차량 9종은 참조되지 않는다. 과거 차량 제거 지시를 존중해 차량을 새 디자인에 재도입하지 않는다.
- 보호자 녹음 삭제는 현재 확인·실행 취소 없이 즉시 실행되므로, 시각 장식보다 먼저 대상 글자와 삭제 범위를 분명히 하고 확인 또는 즉시 실행 취소를 제공하는 UX 안전 관문이 필요하다.

## 권장 아트 방향

기존 성공 도마뱀과 action atlas를 연결하기 쉬운 기본 방향은 `햇살 정원 글자 공방`이다.

- warm cream, deep teal, coral, sun yellow를 공통색으로 쓰고 자음 blue, 모음 orange, 가나다 green을 보조색으로 유지한다.
- low-contrast 환경 배경, 촉각적인 기능 surface, 교육용 글자와 다음 행동의 세 깊이 층을 만든다.
- glossy 3D toy/clay 그림체를 자산 기준으로 삼되 과도한 플라스틱 광택과 랜덤한 그림자 방향을 금지한다.
- 중앙 교육 geometry와 터치 영역은 비워 두고 캐릭터·소품·파티클은 가장자리 안전 영역에만 둔다.
- 보호자 화면은 캐릭터와 파티클보다 종이·공방의 낮은 대비 texture, 명확한 정보 위계와 정돈된 밀도로 프리미엄함을 만든다.
- bitmap에 한글, 숫자, 버튼 문구, 가짜 UI, 워터마크를 생성하지 않는다. 정확한 글자는 Compose와 production Canvas geometry가 렌더링한다.

첫 구현 전 자동 아트 디렉션 역할은 현재 기준 화면을 입력으로 홈·선택·쓰기의 전면 mock 방향을 정확히 세 가지 만든다. 사용자가 한 방향을 선택하기 전에는 production UI를 그 mock에 맞춰 재구축하지 않는다. 다만 P0 데이터 안전 수정, 전 씬 inventory, 측정, 죽은 자산 감사와 자동 검사 강화는 먼저 진행할 수 있다.

## 전체 씬 범위

첫 루프에서 실제 navigation과 동일 APK로 도달 가능 여부를 다시 확인하고 다음 행렬을 확정한다.

1. 홈: 기본, 진입 시작·중간·끝, 카드 기본·눌림, 보호자 길게 누르기.
2. 메뉴 전환: 자음·모음·가나다 각각 시작·중간·끝.
3. 선택: 자음 14개, 모음 10개, 가나다 14개, 첫·중간·마지막, 기본·눌림·선택·뒤로·홈.
4. 쓰기: 초기, 음성 재생, 시범, 획별 진행, 아이 입력, 재시도, 성공, 자동 다음, 홈·다시쓰기·이전·다음.
5. 보호자 overview: 자음·모음·글자 분류, 녹음 관리, 목록 추가, 목록 편집, 빈 목록·중복·현재 위치·진행 상태.
6. 보호자 녹음: 없음, 녹음 중, 준비, 미리 듣기, 다시 녹음, 삭제 확인·취소, 사용자 녹음 온·오프, 권한 승인·거부·재요청, 손상 파일·재생 실패.
7. 보호자 자유 학습: 빈 목록, 한 페이지, 중간·마지막 페이지, 선택, 이동, 삭제, 이어하기, 처음부터.
8. 성공·재시도·학습 완료: animator scale 1과 0, 자동 다음 취소, 완료에서 홈·처음부터.
9. 조립: 현재 production에서 도달 불가로 분류한다. 별도 제품 지시로 재노출이 확정될 때만 target 선택, 조각 순서, 오순서, 완성, 쓰기 전환을 새 범위로 추가한다.

## 루프 순서

활성 루프는 항상 하나만 둔다. 한 루프에서 전 씬을 동시에 고치지 않는다.

### D0 — 전 씬 inventory·데이터 안전·아트 바이블

- 새 최종 APK에서 도달 가능한 모든 씬과 상태를 새 PNG·hierarchy·focus·진입 동작으로 수집한다.
- 보호자 녹음 삭제의 확인 또는 즉시 실행 취소 UX를 독립 P0 제품 결함으로 먼저 해결한다.
- 공통 색·재질·광원·corner·elevation·spacing·typography·icon·background density·motion token을 문서와 코드에 고정한다.
- 현재 APK 크기, raster별 압축 크기와 decode 크기, 메모리와 framestats 기준값을 기록한다.
- 세 가지 full-screen mock을 만들어 사용자 선택 지점에서 production 리디자인을 멈춘다.

### D1 — 홈과 공통 scene shell

- 세 메뉴의 현재 큰 touch 영역과 왼쪽 위 보호자 진입을 유지한다.
- 공통 배경의 깊이, 메뉴별 실제 그림 자산, 현재/눌림/선택 상태와 짧은 진입 연출을 연결한다.
- 글을 읽지 않아도 자음·모음·가나다가 서로 다른 과제라는 점을 모양·색·짧은 시범으로 구분한다.
- 장식이 카드보다 강하거나 보호자 아이콘을 아이의 주 행동처럼 보이게 하면 실패다.

### D2 — 세 선택 화면

- 공통 component와 메뉴별 배경·상징을 적용하되 글자 크기와 터치 영역을 줄이지 않는다.
- 첫·중간·마지막 lesson, 눌림, 선택, 최근 또는 현재 학습 상태를 모양과 명도로 구분한다.
- 자음·모음·가나다의 카드 수와 순서, home callback, 한 화면 전체 노출 계약을 회귀 고정한다.

### D3 — 쓰기 scene 외곽과 음성·도움 상태

- WritingCanvas 1962 × 954 px, 네 조작 168 × 168 px와 교육 geometry를 보존한다.
- 중앙 글자 길 안에는 지속 장식과 파티클을 넣지 않는다.
- 배경, 가장자리 guide character, 음성 재생 halo, 시작점 shimmer와 획 완료의 짧은 잉크 광택만 추가한다.
- 아이가 쓰는 동안 연속 파티클, 손가락을 따라가는 장식, 입력 semantics를 가로채는 overlay를 금지한다.

### D4 — 재시도·성공·자동 다음·완료

- 재시도는 꾸짖는 X 없이 부드러운 가장자리 pulse와 시작점 재강조 후 즉시 다시 쓸 수 있게 한다.
- 성공은 체크·도마뱀·제한된 particle burst를 분리해 완성 글자와 네 조작을 가리지 않는다.
- 학습 완료는 전용 캐릭터·메달 illustration과 홈·처음부터의 두 명확한 행동으로 보상감을 만든다.
- animator scale 0에서도 정적 성공 의미를 wall-clock 기준 최소 1,200ms 보여 주고 자동 다음과 수동 취소가 동작해야 한다.

### D5 — 보호자 overview·분류·진도

- 아이 화면과 같은 브랜드를 유지하되 성인 관리 화면에 맞게 decoration 밀도를 낮춘다.
- 제목, 현재 목록, 주요 작업, 분류, lesson 상태의 순서를 명확히 하고 중복 문구를 줄인다.
- 보조 문구는 최소 14sp, 필수 텍스트 대비 4.5:1, 필수 비텍스트 대비 3:1을 측정한다.
- 분류별 전체 고정 그리드, 192px 이상 lesson cell, 비스크롤 계약을 유지한다.

### D6 — 보호자 녹음과 권한·오류 상태

- 큰 빈 중앙 패널을 상태 illustration·파형·주 행동 중심의 균형 잡힌 layout으로 바꾼다.
- 녹음 없음·녹음 중·준비·재생 중을 색 하나가 아닌 모양·아이콘·문구·motion으로 구분한다.
- 녹음, 정지, 듣기, 다시 녹음, 삭제를 같은 위치 체계로 유지하고 destructive action을 분리한다.
- 권한 거부, 손상 파일, playback 실패에서도 돌아갈 곳과 다음 행동이 분명해야 한다.

### D7 — 자유 학습 목록·편집

- 기존 버튼식 페이지 UI와 현재/전체 페이지 표시를 유지한다.
- 선택된 카드, 이동 가능·불가, 삭제, 이어하기, 처음부터를 명도·shape·semantics로 구분한다.
- 중복 lesson의 순번과 선택 위치를 잃지 않으며 font scale 2.0에서 잘림이 없어야 한다.

### D8 — 공통 파티클·모션·움직임 줄이기

- 여러 particle Composable을 만들지 않고 single Canvas와 seeded particle model로 그린다.
- 홈 ambient는 정지 또는 극저속 6~10개, 메뉴 tap은 6~8개·350~500ms, 성공은 18~24개·700~1,000ms를 상한으로 한다.
- 파티클은 pointer 입력과 접근성 semantics가 없고 글자·시작점·진행 표식·조작과 겹치지 않는다.
- animator scale 0에서는 ambient 0개, 이동·흔들림·overshoot 0, 파티클 대신 의미가 같은 정적 한 프레임을 쓴다.
- 무한 애니메이션은 lifecycle background에서 반드시 멈춘다.

### D9 — 자산·APK·성능 정리

- 미사용 vehicle 9종은 과거 제거 지시와 production 참조 0건을 확인한 뒤 삭제 후보로 다룬다. 새 디자인에 억지로 재사용하지 않는다.
- 현재 26,606,230 byte debug APK보다 커지지 않는 것을 기본 목표로 삼고, 죽은 자산 제거 여유 안에서 새 자산을 구성한다.
- 동시 decoded bitmap 예산은 16 MiB 이하, full-screen bitmap은 한 장만 상주, particle은 최대 24개로 제한한다.
- 고정 흐름 `gfxinfo framestats`에서 deadline miss 3% 미만, frozen frame 0을 목표로 한다.
- 홈→전 화면→홈 10회 고정 상한 뒤 post-GC PSS의 10회 값이 5회 값보다 4 MiB 이상 늘지 않아야 한다.
- minSdk 26·2GB 메모리 profile smoke를 수행하고 성능 통과를 위해 시각 품질을 임의로 제거하지 않는다.

### D10 — 최종 전체 플레이

- 같은 최종 commit·APK에서 과거 캡처를 재사용하지 않고 모든 고유 씬과 중요 상태를 새로 방문한다.
- `docs/전체-플레이-QA-행렬.md`의 PNG·hierarchy·focus·callback·APK SHA 누락을 0건으로 만든다.
- 자동 아트 디렉션, UI/UX, 그래픽 자산, 모션·VFX, Android 성능, 접근성·아이 대리 QA, 최종 QA 역할이 각각 판정한다.
- 새 P0·P1 0건, 진행 방해 P2 0건, 화면 누락 0건일 때만 프리미엄 디자인 에픽을 완료한다.
- D0부터 이 관문 통과 전까지는 `alarmquest-qa` 에뮬레이터에서만 검증하며, 중간 APK를 SM-S931N에 설치하거나 connected test를 실행하지 않는다.
- 통합 관문을 통과한 최종 APK만 SM-S931N에 데이터 보존 덮어쓰기로 무선 설치하고 설치·실행/focus·버전·기기 APK 동일성을 각각 확인한다.

## 자산 생성 계약

- 전용 bitmap이 필요한 루프는 슬롯 bounds를 먼저 측정하고 `imagegen`의 Codex 내장 생성기를 사용한다. 외부 이미지 API, 임시 emoji, 시스템 glyph와 코드로 그린 가짜 illustration을 금지한다.
- 투명 캐릭터·소품·foreground·particle은 RGBA PNG를 사용한다. 완전히 불투명한 scene background만 결정적 crop·검증 뒤 lossless 또는 고품질 WebP를 허용한다.
- background는 2340 × 1080에서 중앙 과제와 주 터치 안전 영역을 비워 생성한다.
- 캐릭터는 성공 도마뱀 화풍을 기준으로 idle, listen, guide, celebrate 네 상태를 일관된 비율·광원·palette로 만든다.
- particle 최소 세트는 512 × 128 RGBA, 128 px 셀 네 개로 별빛·꽃잎·리본·작은 빛점을 제공한다. 더 많은 셀은 실제 상태 구분 가치가 있을 때만 늘린다.
- atlas cell 사이 최소 12 px 투명 gutter, 네 모서리 alpha 0, alpha bbox inset, 검은 배경·halo·셀 침범·문자·워터마크 0건을 자동 검사한다.
- 생성 원본만 저장하고 끝내지 않는다. production resource, 소비 코드, APK 포함, 같은 상태 실화면을 모두 연결한다.
- stretch와 crop으로 캐릭터·아이콘 비율을 왜곡하지 않는다. 반복 panel은 bitmap보다 Compose shape·brush를 우선한다.
- 한글 glyph와 획 안내는 이미지 생성하지 않고 production Canvas geometry를 유지한다.

## UI/UX 수용 기준

- 아이 화면의 주 행동은 글을 읽지 않고 5초 안에 찾을 수 있어야 한다.
- 주 아이 touch target은 최소 64 × 64dp, 간격 최소 12dp를 유지한다.
- WritingCanvas는 최소 1872 × 648 px이며 현재 1962 × 954 px보다 작아지지 않는다.
- 필수 텍스트 대비 4.5:1, 큰 텍스트와 필수 비텍스트 대비 3:1 이상을 측정한다.
- `font_scale=1.0`, `1.5`, `2.0`에서 잘림·겹침 0건을 확인한다.
- TalkBack reading order는 과제, 주 행동, 보조 행동 순이며 raw enum·중복 상태·의미 없는 bitmap 설명을 노출하지 않는다.
- decoration은 의미를 색 하나, motion 하나, 음성 하나에만 의존하게 만들지 않는다.
- 삭제·덮어쓰기 같은 복구 불가능한 동작은 대상과 결과를 미리 보여 주고 확인 또는 실행 취소를 제공한다.

## 중복 방지와 종료 경계

- 같은 화면에 장식 수만 늘리는 반복을 금지한다.
- 화면을 실제로 바꾸지 않는 캡처 재생산, particle 개수만 늘리는 반복, 같은 검증 횟수의 N+1 루프를 금지한다.
- 시각이 풍족해도 다음 행동 발견, 대비, 입력 비가림, 성능 또는 데이터 안전이 나빠지면 기각한다.
- 각 루프는 가장 중요한 실패 하나만 고치고 새 APK·새 화면으로 다시 판정한다.
- 전 대상 씬과 상태를 같은 최종 APK로 전량 확인하기 전에는 `프리미엄 디자인 완료`, `모든 씬 완료`, `IDLE`을 선언하지 않는다.
