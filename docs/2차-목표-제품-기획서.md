# LimDo 2차 목표 제품 기획서

문서 상태: 사용자 지시 반영 기획 0.2

작성일: 2026-08-28

구현 상태: 독립 package·영구 그래픽 검토 계약 완료, 첫 시각 통일 루프 준비

이 문서는 교육과정, 다섯 살 아이 UX·접근성, 제품 로드맵의 세 자동 기획 역할이 만든 초안을 최신 사용자 결정으로 교정한 2차 제품 계약이다. 실제 사람 기획팀, 실제 교사, 실제 아이가 참여하거나 승인한 것으로 표현하지 않는다.

## 한 줄 목표

보호자가 자음·모음·글자를 원하는 수와 순서로 구성하고 각 글자의 `쓰기 전`·`정답 후` 음성을 직접 녹음하면, 아이가 익숙한 보호자의 목소리를 들으며 정답 뒤 다음 쓰기로 자연스럽게 이어 가는 완전 로컬 한글 학습 앱을 만든다.

## 확정된 제품 결정

1. Android namespace와 applicationId는 `com.limdo.hangul`를 사용한다.
2. 진도·설정·보호자 녹음은 cloud backup, device transfer와 원격 저장을 사용하지 않는다.
3. 합성 음성, 내장 성우 음성, 생성 음성, 특정 캐릭터 모사 음성 안내 기획은 제거한다.
4. 음성이 필요하면 보호자가 보호자 전용 메뉴에서 직접 녹음한 파일만 사용한다.
5. 각 lesson에는 `쓰기 전`과 `정답 후`의 두 녹음 칸을 둔다.
6. 정답 후 결과 녹음을 한 번 재생한 다음 다음 lesson으로 자동 진행한다.
7. 하루 글자 수, 시간, 연속 출석, 진도 잠금과 같은 앱 강제 제약을 두지 않는다.
8. 보호자가 원하는 수의 lesson을 원하는 순서로 구성하며 같은 lesson을 여러 번 넣을 수도 있다.
9. 보호자 학습 목록이 없으면 현재처럼 모든 글자를 자유롭게 선택하고 메뉴 안의 이전·다음 순서를 사용한다.
10. 홈·다시쓰기·이전·다음 네 조작은 녹음 재생·자동 진행 대기 중에도 항상 사용할 수 있다.

## 현재 제품 기준선

### 확인된 구현

- Android·Kotlin·Jetpack Compose 기반의 가로형 로컬 앱이며 최소 SDK 26, target SDK 36이다.
- 홈에 `자음·모음·가나다` 세 메뉴가 있고 선택→쓰기→이전·다음→홈 흐름이 동작한다.
- 아이가 현재 선택할 수 있는 범위는 자음 14개, 기본 모음 10개, `가~하` 14개로 총 38개다. 모든 글자는 잠금 없이 선택할 수 있다.
- 내부 수업 데이터는 총 54개다. 현재 메뉴에 노출되지 않은 `ㅐ`, `갸·거·겨·고·교·구·규·그·기`, `각·간·갇·갈·감·갑`의 자형·획수·방향 model도 있다.
- 2340 × 1080에서 WritingCanvas는 1962 × 954 px이며 홈·다시쓰기·이전·다음 네 조작은 각각 168 × 168 px이고 항상 활성이다.
- 큰 안내선, 현재 획 점선, 시작·끝 표식, 동적 방향 표식과 입력 판정이 같은 geometry를 사용한다.
- 아이용 완화 판정, 실패 그림 없는 짧은 재시도 효과와 자동 초기화, 전체 화면 성공 연출이 구현돼 있다.
- 현재 앱에는 음성 파일·실제 녹음·실제 재생 연결이 없다. 과거 음성용 문구 model은 남아 있지만 제품 동작으로 사용되지 않는다.
- 현재 manifest에는 인터넷·카메라·마이크 권한, 서버, 로그인, 광고, 분석 SDK가 없다.
- 단위 테스트 108개와 lint·debug build·정확한 에뮬레이터 아이 대리 QA가 통과한 상태다.

### 제품으로서 남은 핵심 결손

- 보호자 전용 메뉴와 보호자 lesson 목록 편집이 없다.
- lesson별 `쓰기 전`·`정답 후` 녹음, 미리 듣기, 다시 녹음과 삭제가 없다.
- 녹음 재생 중복·중단·오류·화면 이탈을 관리하는 lifecycle이 없다.
- 정답 뒤 결과 재생과 다음 lesson 자동 진행이 연결돼 있지 않다.
- 앱 종료 뒤 이어지는 보호자 학습 목록, 최근 위치와 진도 요약이 없다.
- 내부에 준비된 16개 수업은 실제 메뉴 흐름에서 사용할 수 없다.
- Android UI 계측 테스트, 업그레이드 시 로컬 데이터 보존, 정식 서명 release APK 관문이 없다.
- 실제 아이 관찰은 아직 실행하지 않았다. 따라서 학습 효과나 실제 독립 사용성을 검증했다고 표현하지 않는다.

## 제품 원칙

1. 한 화면에는 아이가 해야 할 핵심 행동 하나만 둔다.
2. 학습 lesson 수와 순서는 보호자가 정하며 앱이 일일 목표나 제한을 정하지 않는다.
3. 보호자 목록은 진행 경로이지 잠금이 아니다. 아이는 언제든 자유 쓰기와 네 조작을 사용할 수 있다.
4. 아이 화면에는 점수, 오답 수, 등급, 순위, 남은 일일 목표와 연속 출석을 두지 않는다.
5. 실패는 벌점이 아니라 다음 도움을 고르는 신호로만 사용한다.
6. 쓰기 성공과 글자를 읽거나 소리로 구별하는 능력을 같은 성취로 취급하지 않는다.
7. 손글씨 원시 좌표와 아이의 이름·생년월일·사진·음성은 저장하지 않는다.
8. 보호자가 명시적으로 녹음한 두 음성만 app-private `noBackupFilesDir`에 저장한다.
9. 녹음이 없거나 마이크 권한이 거부돼도 현재 무음 시각 흐름으로 전체 학습을 진행할 수 있다.
10. 모든 진도·설정·학습 목록·음성은 기기 안에만 두고 OS backup과 원격 기능을 사용하지 않는다.
11. 자동 QA, 아이 대리 QA, 실제 아이 관찰과 학습 효과 검증을 구분한다.

## 보호자 전용 메뉴

### 진입

- 홈의 보호자 아이콘을 2초간 길게 눌러 진입한다.
- 아이의 쓰기 화면 홈 버튼과 위치·모양을 분리한다.
- 보호자 메뉴는 글을 읽는 성인을 전제로 하되 주요 동작은 명확한 아이콘과 상태를 함께 쓴다.
- 보호자 메뉴를 닫으면 녹음·재생·권한 요청을 모두 정리하고 아이 화면으로 돌아간다.

### 학습 순서 만들기

- `자음·모음·글자` 탭에서 lesson을 원하는 수만큼 고른다.
- 선택한 lesson은 보호자 목록에서 끌어 순서를 바꾸고, 제거하고, 같은 lesson을 반복 추가할 수 있다.
- 앱은 최소·최대 글자 수나 하루 기준을 강제하지 않는다.
- 목록은 자동으로 날짜가 바뀌었다고 초기화하지 않는다.
- 보호자는 현재 위치부터 이어하기, 처음부터 다시 시작하기, 목록 비우기를 선택할 수 있다.
- 목록을 비워도 자음·모음·가나다의 자유 선택은 항상 사용할 수 있다.

### lesson별 음성 관리

각 lesson 카드에 다음 두 칸을 둔다.

1. `쓰기 전`: 새 글자 화면이 안정적으로 표시된 직후, 쓰기를 받기 전에 한 번 재생한다.
2. `정답 후`: 성공 연출과 함께 한 번 재생한 뒤 다음 lesson 자동 진행의 기준이 된다.

각 칸은 다음 동작을 제공한다.

- 녹음 시작·정지
- 녹음 상태와 길이 확인
- 미리 듣기·정지
- 다시 녹음
- 한 녹음 삭제
- 해당 lesson의 두 녹음 삭제

녹음되지 않은 칸은 오류가 아니라 `무음` 상태다. 보호자 녹음은 짧은 cue를 위한 것이므로 한 파일의 최대 길이는 8초로 제한하고 시간이 끝나면 안전하게 녹음을 마친다. 이는 아이의 학습량 제한이 아니라 파일과 재생 lifecycle을 안정적으로 유지하기 위한 녹음 길이 상한이다.

### 마이크 권한

- `RECORD_AUDIO`는 보호자가 녹음 버튼을 누를 때만 요청한다.
- 권한을 거부하거나 나중에 취소해도 미리 녹음된 파일의 재생과 아이의 무음 쓰기 기능은 유지한다.
- 권한이 없을 때 반복 요청하지 않고 보호자 화면에서 필요한 이유와 시스템 설정 경로를 설명한다.
- 아이 화면에서는 마이크 권한을 요청하거나 녹음을 시작하지 않는다.
- 인터넷 권한과 외부 저장소 권한은 추가하지 않는다.

## 로컬 음성 저장 계약

- 저장 위치: 앱 전용 `noBackupFilesDir/guardian_voice/`
- 식별 기준: 안정적인 `lessonId`와 `START`·`SUCCESS` event
- 권장 파일명: `<lessonId>_start.m4a`, `<lessonId>_success.m4a`
- 기록 형식: 기기에서 지원하는 AAC/MPEG-4 계열, 최대 8초
- 저장 방식: 임시 파일에 녹음한 뒤 완료된 파일만 원자적으로 교체
- 다시 녹음: 새 파일 저장 성공 뒤 이전 파일 삭제
- 앱 업데이트: 같은 applicationId에서 파일 유지
- 앱 데이터 삭제·앱 제거: 녹음 삭제
- 진도 초기화: 기본적으로 녹음 보존
- 녹음 전체 삭제: 보호자 메뉴에서 별도 확인 뒤 실행
- cloud backup·device transfer·외부 공유·분석 업로드: 사용 안 함

손상되거나 재생할 수 없는 파일은 해당 칸을 무음으로 처리하고 보호자 화면에만 다시 녹음 상태를 표시한다. 아이 학습을 중단시키지 않는다.

## 아이 쓰기 흐름

### lesson 진입과 쓰기 전 음성

1. lesson geometry·점선·시작점·네 조작을 먼저 그린다.
2. `쓰기 전` 녹음이 있으면 한 번 재생한다.
3. 재생 중에는 쓰기판에 소리 재생을 나타내는 부드러운 움직임을 보여 주고 새 획 입력만 잠시 기다린다.
4. 홈·다시쓰기·이전·다음은 계속 사용할 수 있다.
5. 녹음이 없거나 재생에 실패하면 기다리지 않고 바로 쓰기를 시작한다.
6. 다시쓰기를 누르면 현재 입력을 지우고 `쓰기 전` 녹음을 다시 한 번 재생한다.
7. 이전·다음·홈을 누르면 현재 재생과 예약된 자동 진행을 즉시 취소한다.

### 정답과 자동 다음

1. 정답이 되면 입력을 성공 상태로 고정하고 전체 화면 성공 원형을 보여 준다.
2. 현재 lesson의 `정답 후` 녹음이 있으면 한 번만 재생한다.
3. 결과 녹음이 끝나면 다음 lesson으로 자동 진행한다.
4. 결과 녹음이 없거나 재생에 실패하면 기존 성공 연출의 최소 노출 시간이 끝난 뒤 자동 진행한다.
5. 같은 성공 event가 재구성되거나 앱이 foreground로 돌아와도 결과 녹음과 자동 진행을 중복 실행하지 않는다.
6. 자동 진행 대기 중 홈·다시쓰기·이전·다음을 누르면 예약을 취소하고 사용자가 고른 동작을 우선한다.

다음 lesson의 정의는 현재 모드에 따라 다르다.

- 보호자 목록 모드: 보호자가 정한 다음 항목. 같은 lesson이 반복돼도 목록 순서를 그대로 따른다.
- 보호자 목록 마지막: 완료 화면에서 `처음부터 다시`와 `홈`을 제공하며 자동 순환하지 않는다.
- 자유 쓰기 모드: 현재 메뉴의 기존 다음 순서로 이동하고 마지막 뒤 첫 글자로 순환한다.

새 lesson으로 이동하면 입력·성공·재시도 상태를 깨끗하게 지우고 해당 lesson의 `쓰기 전` 녹음을 한 번 재생한다.

### 재생 lifecycle

- 동시에 하나의 녹음만 재생한다.
- 새 재생 요청은 이전 재생을 중단·해제한 뒤 시작한다.
- 홈·이전·다음·보호자 메뉴·앱 background·화면 종료에서 재생과 자동 진행 예약을 취소한다.
- 전화·다른 앱 audio focus 상실 시 재생을 멈추고 시각 흐름은 유지한다.
- clip 종료 callback과 timeout을 함께 두어 손상 파일 때문에 다음 진행이 멈추지 않게 한다.
- 앱 재실행 뒤 완료되지 않은 재생을 이어 재생하지 않는다. 현재 lesson의 안전한 시작 상태에서 다시 시작한다.

## 로컬 진도와 보호자 요약

보호자가 다음 학습을 직접 정하므로 앱은 자동 추천이나 일일 목표를 만들지 않는다. 진도는 보호자가 판단할 수 있는 사실만 보여 준다.

### 저장할 최소 정보

- 안정적인 `lessonId`
- 마지막 연습·완료 시각
- 서로 다른 실행에서 완료한 횟수
- 마지막 도움 단계: `혼자 완성·도움 후 완성·연습 중`
- 현재 보호자 목록과 순서, 현재 위치
- 각 lesson의 두 녹음 존재 여부와 파일 metadata
- 움직임 줄이기와 기본 도움 수준 설정
- 저장 형식 버전

### 저장하지 않을 정보

- 손가락 원시 좌표와 완성 획 궤적
- 아이의 오답 화면, 이름, 생년월일, 사진과 음성
- 서버 식별자, 광고 식별자, 분석 event
- 점수, 순위, 일일 목표, 연속 출석과 비교용 통계

보호자 화면에는 최근 연습·완료·도움 상태만 보여 주고 `다음에 할 lesson`은 보호자가 목록에서 직접 고른다. 앱은 자동 숙달·뒤처짐·진급을 판정하지 않는다.

## 2차 교육과정

### 1단계 — 현재 38개 자유 쓰기와 보호자 목록

- 현재 자음 14개, 기본 모음 10개, `가~하` 14개를 유지한다.
- 보호자는 이 38개를 원하는 수·순서·반복으로 구성한다.
- 각 lesson의 시작 전·정답 후 녹음을 독립적으로 관리한다.
- 안내 강도와 판정 정확도를 분리하고 역방향·잘못된 획순·큰 이탈 거부는 유지한다.

### 2단계 — 자음과 모음 조립

- `ㄱ`과 모음 조각을 네모 칸에 놓아 `가·거·고·구·그·기`를 만든다.
- 세로 모음은 초성 오른쪽, 가로 모음은 초성 아래에 놓이는 구조를 모양과 움직임으로 보여 준다.
- 익숙해진 뒤 `갸·겨·교·규`를 추가한다.
- 조립 뒤 같은 글자를 쓰기판에서 따라 써 구조와 손글씨를 연결한다.
- 새 lesson은 보호자 목록과 두 녹음 관리에 자동으로 나타나야 한다.

### 3단계 — 받침 없는 첫 확장

- 첫 범위는 `ㄱ·ㄴ·ㄷ × 10개 기본 모음`의 30음절이다.
- `ㄱ` 행의 9개 추가 글자는 현재 내부 model을 우선 활용한다.
- `ㄴ`·`ㄷ` 행은 자형·획 분리·방향·판정을 좁은 묶음별로 검증한다.
- 선택 화면에 30개를 한꺼번에 늘어놓지 않고 초성별 10개 묶음으로 제공한다.
- 앱이 일괄 학습을 요구하지 않으며 보호자가 필요한 lesson만 목록에 추가한다.

### 4단계 — 받침 한 칸 더하기

- `가↔각`, `가↔간` 비교로 받침의 아래 자리를 먼저 익힌다.
- 이후 이미 내부 model이 있는 `갇·갈·감·갑`을 좁은 묶음으로 추가한다.
- 겹받침은 2차 범위에 포함하지 않는다.
- 받침 lesson도 같은 보호자 목록·두 녹음·자동 다음 계약을 사용한다.

## 마일스톤

모든 M1~M4 구현 루프는 `docs/그래픽-시스템-루프-계약.md`를 따른다. 자동 그래픽 디자인 역할이 자산 필요 여부를 먼저 판정하고, 필요하면 Codex 내장 이미지 생성기로 자체 생성해 production에 적용한다. 동일 상태의 변경 전·후 2340 × 1080 실화면 검토가 통과하지 않으면 가장 중요한 결함 하나만 수정·재생성해 반복한다.

M1~M4와 그래픽 완료 감사 뒤에는 M5의 시작으로 `docs/전체-플레이-QA-행렬.md`를 새 최종 APK에서 전량 수집한다. 전체 화면 누락 0건과 새 P0·P1 0개, 진행 방해 P2 0개 전에는 구현 완료를 선언하거나 `IDLE`로 종료하지 않는다.

### M0 — 정식 앱 식별자와 완전 로컬 경계

- namespace·applicationId·source package를 `com.limdo.hangul`로 통일한다.
- `android:allowBackup=false`를 적용한다.
- Android 11 이하 `fullBackupContent`와 Android 12 이상 `dataExtractionRules`에서 모든 app data domain의 cloud backup·device transfer를 제외한다.
- 인터넷·외부 저장소 권한 0개를 유지한다.
- 최종 APK manifest와 새 package 설치·실행을 검증한다.

완료 관문: source·APK·에뮬레이터에서 package와 무백업 정책이 일치한다.

### M1 — 보호자 녹음 라이브러리

여러 개의 좁은 루프로 구현한다.

1. 보호자 길게 누르기 진입과 자음·모음·글자 lesson 목록
2. `쓰기 전` 녹음·미리 듣기·다시 녹음·삭제
3. `정답 후` 녹음·미리 듣기·다시 녹음·삭제
4. 권한 거부·취소·손상 파일·앱 background lifecycle
5. 기존 사용되지 않는 합성 음성 문구·재생 상태 model 제거 또는 보호자 녹음 event model로 교체

완료 관문: 모든 현재 lesson의 두 칸이 로컬 파일과 정확히 연결되고, 다른 lesson 파일을 덮어쓰지 않으며 backup·외부 저장·네트워크가 0건이다.

### M2 — 쓰기 전·정답 후 재생과 자동 다음

- 쓰기 전 녹음을 한 번 재생한 뒤 입력을 시작한다.
- 정답 후 녹음을 한 번 재생한 뒤 다음 lesson으로 자동 진행한다.
- 녹음 없음·재생 오류는 무음 시각 흐름으로 대체한다.
- 중복 callback, 빠른 탭, 화면 이탈과 background에서 재생·자동 진행을 취소한다.
- 네 조작은 항상 활성이고 수동 동작이 자동 진행보다 우선한다.

완료 관문: 시작·성공 event당 정확히 1회 재생, 자동 다음 정확히 1회, 무음 대안과 수동 취소가 자동·에뮬레이터·실제 기기에서 통과한다.

### M3 — 보호자 자유 학습 목록과 이어하기

- 보호자가 lesson을 수 제한 없이 추가·반복·정렬·삭제한다.
- 목록 현재 위치를 로컬 저장하고 앱 재실행 뒤 이어간다.
- 마지막 lesson은 자동 순환하지 않고 완료 화면으로 간다.
- 자유 쓰기는 기존 메뉴 선택과 순환을 유지한다.
- 최근 연습·완료·도움 상태와 녹음 존재 여부를 보호자에게 보여 준다.

완료 관문: 임의 길이·중복을 포함한 보호자 목록이 순서대로 진행되고 강제 종료·업데이트 뒤에도 위치와 녹음이 보존된다.

### M4 — 단계적 도움·접근성과 교육 확장

- 반복 어려움에 따라 시범 속도·시작점·안내 강도를 조정하되 판정 안전 경계를 유지한다.
- TalkBack 순서와 Custom Canvas 충돌, 시스템 움직임 줄이기, 큰 글자 설정을 검증한다.
- 자음+모음 조립 뒤 `ㄱ·ㄴ·ㄷ × 기본 모음`을 좁은 lesson 묶음으로 확장한다.
- 새 lesson을 보호자 목록·녹음·재생·진도 schema에 빠짐없이 연결한다.

완료 관문: 새 교육 범위와 보호자 음성 흐름에서 P0·P1 0개, 진행 방해 P2 0개다.

### M5 — 실제 사용 검증과 로컬 릴리스

- API 26과 API 36, 기준 2340 × 1080과 보조 가로 해상도에서 핵심 흐름을 검증한다.
- 보호자 목록 작성→두 음성 녹음→아이 시작 재생→쓰기→성공 재생→자동 다음→완료의 Android UI 계측 테스트를 추가한다.
- 녹음·재생 중 시스템 권한 취소, audio focus 상실, 화면 종료, 앱 재실행과 저장 공간 부족을 검증한다.
- SM-S931N에서 녹음·재생·쓰기·자동 다음과 반복 이동의 크래시·멈춘 연출·지속 메모리 증가 없음 여부를 확인한다.
- 보호자가 정한 실제 학습 순서로 대상 아이를 보호자 감독 아래 관찰한다. 앱은 관찰 시간과 lesson 수를 강제하지 않는다.
- P0·P1 0개와 반복 진행을 막는 P2 0개 뒤 versionCode를 올리고 정식 서명 release APK의 서명·Manifest·업그레이드 설치·로컬 파일 보존을 확인한다.

완료 관문: 실제 아이 관찰과 정식 로컬 APK 검증을 분리해 완료한다. 실제 관찰을 수행하지 못했다면 구현 완료와 실제 사용성 검증 완료를 같은 상태로 표현하지 않는다.

## 성공 지표

원격 분석은 사용하지 않는다. 자동 측정, 기기 내부 사실, 보호자 감독 관찰만 사용한다.

### 자동·기기 지표

- 모든 configured lesson은 `START`·`SUCCESS` 파일을 서로 독립적으로 저장한다.
- start·success event당 재생은 정확히 한 번이고 동시에 두 파일이 재생되지 않는다.
- 정답 한 번에 자동 다음은 정확히 한 번 발생한다.
- 보호자 목록은 길이·중복과 관계없이 저장된 순서를 그대로 따른다.
- 녹음 없음·권한 거부·손상 파일·재생 오류에도 쓰기와 다음 진행이 멈추지 않는다.
- 앱 재실행·업데이트 뒤 목록 위치·진도·녹음이 유지된다.
- cloud backup·device transfer·외부 저장·네트워크 전송 0건이다.
- 손글씨 원시 좌표와 아이 개인정보 저장 0건이다.

### 실제 아이 관찰 항목

- 보호자가 정한 첫 lesson에서 녹음과 쓰기 시작의 순서를 이해하는가.
- 녹음 뒤 시작점을 찾고 추가 문장을 읽지 않고 쓰는가.
- 자연스러운 재시도 뒤 활동을 중단하지 않고 다시 시작하는가.
- 정답 후 보호자 목소리와 성공 화면을 결과로 인식하는가.
- 자동으로 바뀐 다음 글자를 새 과제로 구분하는가.
- 홈·다시쓰기·이전·다음으로 자동 흐름을 원할 때 바꿀 수 있는가.
- 보호자가 정한 마지막 lesson 뒤 완료 상태를 이해하는가.

관찰에서는 망설임, 무작위 탭, 보호자 도움, 재시도 뒤 행동, 자발적 계속·종료 여부를 사실로 기록한다. 정해진 시간이나 글자 수를 채우지 않은 것을 실패로 기록하지 않는다.
