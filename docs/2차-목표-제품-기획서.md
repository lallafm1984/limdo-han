# LimDo 2차 목표 제품 기획서

문서 상태: 기획 초안 0.1  
작성일: 2026-08-28  
구현 상태: 시작 안 함

이 문서는 교육과정, 다섯 살 아이 UX·접근성, 제품 로드맵의 세 자동 기획 역할이 현재 저장소와 최신 QA 근거를 읽고 통합한 2차 제품 계약이다. 실제 사람 기획팀, 실제 교사, 실제 아이가 참여하거나 승인한 것으로 표현하지 않는다.

## 한 줄 목표

다섯 살 아이가 글을 읽지 않고도 매일 약 5분 동안 추천된 세 글자를 스스로 연습하고 기분 좋게 끝내며, 보호자는 개인정보를 외부로 보내지 않고 기기 안에서 다음 연습 대상을 이해할 수 있는 로컬 한글 학습 앱을 만든다.

2차 목표의 핵심은 글자 수 확대가 아니라 `이어지는 학습`이다. 다음 날 앱을 다시 열었을 때 최근 활동과 다음 연습이 연결되지 않으면 많은 글자를 추가해도 제대로 된 학습 제품으로 보지 않는다.

## 현재 제품 기준선

### 확인된 구현

- Android·Kotlin·Jetpack Compose 기반의 가로형 로컬 앱이다. 최소 SDK는 26이고 현재 `versionCode 1`, `versionName 0.1.0`, `applicationId com.example.limdo`다.
- 홈에 `자음·모음·가나다` 세 메뉴가 있고 선택→쓰기→이전·다음→홈 흐름이 동작한다.
- 아이가 현재 선택할 수 있는 범위는 자음 14개, 기본 모음 10개, `가~하` 14개로 총 38개다. 모든 글자는 잠금 없이 선택할 수 있다.
- 내부 수업 데이터는 총 54개다. 현재 메뉴에 노출되지 않은 `ㅐ`, `갸·거·겨·고·교·구·규·그·기`, `각·간·갇·갈·감·갑`의 자형·획수·방향 모델도 있다.
- 2340 × 1080에서 WritingCanvas는 1962 × 954 px이며, 홈·다시쓰기·이전·다음 네 조작은 각각 168 × 168 px이고 항상 활성이다.
- 큰 안내선, 현재 획 점선, 시작·끝 표식, 동적 방향 표식과 입력 판정이 같은 geometry를 사용한다.
- 아이용 완화 판정, 실패 그림 없는 짧은 재시도 효과와 자동 초기화, 전체 화면 성공 연출이 구현돼 있다.
- 인터넷·카메라·마이크 권한, 서버, 로그인, 광고, 분석 SDK가 없다.
- 단위 테스트 106개와 lint·debug build·정확한 에뮬레이터 아이 대리 QA가 통과한 상태다.

### 제품으로서 남은 핵심 결손

- 앱 종료 뒤 이어지는 학습 진도, 최근 글자, 추천 세션이 없다.
- 모든 선택 카드가 같은 우선순위여서 아이가 오늘 무엇을 하면 되는지 알 수 없다.
- 반복해서 어려워할 때 시범과 도움 수준이 달라지지 않는다.
- 세션 종료 개념과 보호자용 로컬 요약·초기화 화면이 없다.
- 내부에 준비된 16개 수업은 실제 메뉴 흐름에서 사용할 수 없다.
- Android UI 계측 테스트, 업그레이드 시 진도 보존, 정식 서명 release APK 관문이 없다.
- 실제 아이 관찰은 아직 실행하지 않았다. 따라서 학습 효과나 실제 독립 사용성을 검증했다고 표현하지 않는다.
- 현재 제품에서 자동차와 실제 음성이 제거됐지만 일부 오래된 관찰·교육 문서에는 과거 표현이 남아 있다.

## 제품 원칙

1. 한 화면에는 아이가 해야 할 핵심 행동 하나만 둔다.
2. 기본 세션은 세 글자 또는 약 5분이며 시간 제한을 화면에 표시하지 않는다.
3. 추천은 제공하지만 글자·단계·이전·다음·홈을 잠그지 않는다.
4. 아이 화면에는 점수, 오답 수, 등급, 순위, 연속 출석과 손실 표현을 두지 않는다.
5. 실패는 기록할 벌점이 아니라 다음 도움을 고르는 신호로만 사용한다.
6. 쓰기 성공과 글자를 읽거나 소리로 구별하는 능력을 같은 성취로 취급하지 않는다.
7. 손글씨 원시 좌표, 아이 이름, 생년월일, 얼굴, 음성을 저장하지 않는다.
8. 모든 진도와 설정은 기기 안에만 두며 서버·계정·분석을 추가하지 않는다.
9. 무음 상태만으로 전체 흐름이 완결되어야 한다. 음성은 사용자가 별도 승인한 독창적 로컬 음성만 후속 범위에서 검토한다.
10. 자동 QA, 아이 대리 QA, 실제 아이 관찰과 학습 효과 검증을 구분한다.

## 핵심 사용자 흐름

### 첫 사용

1. 아이가 기존 세 메뉴 중 하나를 고른다.
2. 처음 고른 메뉴에서는 교육 순서의 첫 세 글자를 추천한다.
   - 자음: `ㄱ·ㄴ·ㄷ`
   - 모음: `ㅏ·ㅑ·ㅓ`
   - 가나다: `가·나·다`
3. 추천 카드는 한 번만 부드럽게 강조되며 나머지 카드도 모두 선택 가능하다.
4. 아이가 한 글자를 쓰고 성공하면 해당 세션의 꽃 또는 별 하나가 채워진다.
5. 세 글자 뒤에는 `집`과 `하나 더`의 두 큰 그림 동작으로 끝내거나 계속한다.

### 다시 방문

1. 홈의 세 카드 위치와 색은 유지한다.
2. 마지막으로 사용한 메뉴 카드가 한 번만 천천히 빛나 이어 할 곳을 보여 준다.
3. 메뉴에 들어가면 `익숙한 글자 1 + 다시 볼 글자 1 + 새 글자 1`을 기본 추천한다.
4. 아이가 다른 글자를 고르면 추천을 무시한 실패로 기록하지 않는다.
5. 앱이나 기기를 다시 시작해도 마지막 세션과 진도는 보존한다.

### 쓰기와 재시도

1. 현재 1962 × 954 px 쓰기판과 네 상시 활성 조작을 유지한다.
2. 첫 어려움에는 현재의 짧은 밝기·흔들림 뒤 자동 재시작을 사용한다.
3. 같은 글자에서 다시 어려워하면 시범 속도를 낮추고 현재 획을 한 번 더 보여 준다.
4. 또 어려워하면 시작점과 안내선을 더 강하게 보여 준다.
5. 도움 단계가 높아져도 역방향·잘못된 획순·큰 이탈을 성공으로 처리하지 않는다.
6. 아이 화면에는 재시도 횟수나 실패 문구를 표시하지 않는다.

### 성공과 세션 종료

1. 현재 전체 화면 성공 원형을 유지하되 입력과 네 버튼을 막지 않는다.
2. 자동으로 다음 글자로 넘기지 않고 오른쪽 다음 버튼을 한 번만 부드럽게 강조한다.
3. 세 글자를 마치면 연습한 세 글자와 채워진 꽃·별을 보여 준다.
4. 아이는 `집` 또는 `하나 더`를 선택한다. 어느 선택도 실패나 중단으로 기록하지 않는다.

### 보호자 흐름

1. 홈의 보호자 아이콘을 2초간 길게 눌러 진입한다. 아이의 홈 버튼과 분리한다.
2. 보호자는 최근 연습, `처음·연습 중·익숙해짐·다시 보기`, 도움 수준을 확인한다.
3. 세션 글자 수를 2·3·5개 중 선택하고 움직임 줄이기와 기본 도움 수준을 정한다.
4. 전체 진도 초기화는 대상과 결과를 명확히 보여 준 뒤 실행한다.
5. 보호자 화면에도 아이를 비교하거나 뒤처짐으로 표현하는 문구를 쓰지 않는다.

## 로컬 진도 모델

아이에게는 숫자 진도를 노출하지 않고 보호자와 추천 규칙에서만 사용한다.

### 저장할 최소 정보

- 안정적인 `lessonId`
- 마지막 연습 시각과 마지막 완료 시각
- 서로 다른 세션에서 완료한 횟수
- 마지막 도움 단계: `혼자 완성·도움 후 완성·연습 중`
- 보호자용 상태: `처음·연습 중·익숙해짐·다시 보기`
- 완료하지 않은 현재 세션의 lesson 목록과 현재 위치
- 세션 글자 수, 움직임 줄이기, 기본 도움 수준 설정
- 저장 형식 버전

### 저장하지 않을 정보

- 손가락 원시 좌표와 완성 획 궤적
- 오답 화면이나 실패 그림
- 아이 이름·생년월일·사진·음성
- 서버 식별자, 광고 식별자, 분석 이벤트
- 연속 출석, 점수, 순위, 비교용 통계

### 상태 원칙

- 한 번 성공했다고 영구 숙달로 표시하지 않는다.
- 서로 다른 세션에서의 완료와 필요했던 도움을 함께 본다.
- `다시 보기`는 벌점이 아니라 추천 우선순위다.
- 데이터가 없거나 손상되면 앱이 안전한 첫 사용 상태로 열리고 기존 쓰기 기능은 계속 사용할 수 있어야 한다.
- 앱 업데이트 덮어쓰기 뒤에도 같은 `lessonId`의 기록이 유지돼야 한다.

## 2차 교육과정

### 1단계 — 안내를 받으며 익숙해지기

- 현재 38개 선택 범위를 유지한다.
- 추천 세션과 반복 도움을 연결해 글자 모양·시작점·방향에 익숙해지게 한다.
- 익숙해진 글자는 완전 안내→옅은 안내→시작점 중심 안내를 제안할 수 있지만 언제든 완전 안내로 돌아간다.
- 안내 강도와 판정 정확도를 분리한다. 안내가 줄어도 교육용 자형·획순·방향 계약은 바꾸지 않는다.

### 2단계 — 자음과 모음 조립

- `ㄱ`과 모음 조각을 네모 칸에 놓아 `가·거·고·구·그·기`를 만든다.
- 세로 모음은 초성 오른쪽, 가로 모음은 초성 아래에 놓이는 구조를 모양과 움직임으로 보여 준다.
- 익숙해진 뒤 `갸·겨·교·규`를 추가한다.
- 조립 뒤 같은 글자를 쓰기판에서 따라 써 구조와 손글씨를 연결한다.

### 3단계 — 받침 없는 첫 확장

- 첫 범위는 `ㄱ·ㄴ·ㄷ × 10개 기본 모음`의 30음절이다.
- `ㄱ` 행의 9개 추가 글자는 현재 내부 model을 우선 활용한다.
- `ㄴ`·`ㄷ` 행은 자형·획 분리·방향·판정을 좁은 묶음별로 새로 검증한다.
- 선택 화면에 30개를 한꺼번에 늘어놓지 않고 초성별 10개 묶음으로 제공한다.
- 이전·다음은 현재 선택한 묶음 안에서 순환한다.

### 4단계 — 받침 한 칸 더하기

- `가↔각`, `가↔간` 비교로 받침의 아래 자리를 먼저 익힌다.
- 이후 이미 내부 model이 있는 `갇·갈·감·갑`을 좁은 묶음으로 추가한다.
- 받침 위치를 반복 혼동하면 잠그지 않고 받침 수업을 끝내고 2단계 조립으로 돌아간다.
- 겹받침은 2차 범위에 포함하지 않는다.

### 조건부 후속 — 소리와 생활 낱말

- 현재 2차 기본 범위에는 넣지 않는다.
- 실제 아이 관찰에서 시각 안내만으로 부족하다는 근거가 있고, 사용자가 독창적 로컬 음성 샘플을 승인한 뒤에만 소리 구별을 별도 목표로 연다.
- 음성 없는 상태에서 쓰기 성공을 읽기·소리 구별 성취로 표현하지 않는다.
- 생활 낱말은 아이가 이미 아는 대상만 2~3개씩 제공하며, 낱말 지식 부족을 아이의 실패로 기록하지 않는다.

## 마일스톤

### M0 — 제품 계약과 개인정보 기반 정리

목표: 진도 저장 전에 바뀌기 어려운 제품 경계를 확정한다.

- 정식 `applicationId`를 확정한다. 현재 `com.example.limdo`는 개발용 값이므로 공개 배포 가능성이 있다면 지금 변경한다.
- 기본 백업 정책은 `android:allowBackup=false`로 권고한다. OS 백업을 쓰려면 저장 범위와 복원 동작을 별도 명시한다.
- 자동차·음성 등 현재 제품과 어긋난 오래된 문서를 최신 무음·비자동차 계약으로 정리한다.
- 로컬 진도 schema, migration, 손상 복구, 전체 초기화 계약을 테스트로 고정한다.
- 새 인터넷·카메라·마이크·민감 권한 0개를 유지한다.

완료 관문: 패키지·백업 결정, versioned 진도 모델, 개인정보 저장 목록, 문서 일치와 자동 검사가 통과한다.

### M1 — 하루 세 글자와 이어하기

목표: 현재 쓰기 앱을 다음 날 이어지는 학습 제품으로 바꾼다.

- 성공 결과와 마지막 메뉴·lesson을 로컬 저장한다.
- 첫 세 글자와 `익숙한 1 + 다시 볼 1 + 새 글자 1` 추천 규칙을 결정적이고 테스트 가능하게 구현한다.
- 홈의 마지막 메뉴와 선택 화면의 추천 글자를 한 번만 강조한다.
- 쓰기 화면에 글 대신 꽃·별 세 개로 세션 진행을 보여 준다.
- 세션 완료 화면의 `집·하나 더`를 구현한다.
- 강제 종료·재부팅·덮어쓰기 설치 뒤 이어하기와 중복 완료 방지를 검증한다.
- 현재 38개 글자와 네 조작은 계속 잠금 없이 사용할 수 있어야 한다.

완료 관문: 홈→추천→세 글자→완료→다음 날 이어하기 전체가 자동·에뮬레이터·실제 기기에서 통과한다.

### M2 — 단계적 도움과 보호자 요약

목표: 아이에게 실패를 보여 주지 않으면서 필요한 도움을 늘리고 보호자가 상태를 이해하게 한다.

- 반복 어려움에 따라 시범 속도·시작점·안내 강도를 조정한다.
- 판정 허용치의 상한과 역방향·획순·큰 이탈 거부를 유지한다.
- 보호자 길게 누르기 진입, 최근 연습·도움 상태·세션 길이·움직임 줄이기·초기화를 구현한다.
- 아이 화면에는 실패 횟수와 평가 문구를 표시하지 않는다.
- TalkBack 순서와 Custom Canvas 충돌, 시스템 움직임 줄이기, 큰 글자 설정을 검증한다.

완료 관문: 반복 어려움·보호자 설정·초기화·접근성 흐름에서 P0·P1 0개, 진행 방해 P2 0개다.

### M3 — 음절 조립과 받침 없는 첫 확장

목표: 따라 쓰기를 글자 구조 이해로 확장한다.

- 자음+모음 조립 놀이를 먼저 구현한다.
- `ㄱ` 기본 모음 행을 실제 메뉴와 추천 흐름에 연결한다.
- 실제 관찰 근거 뒤 `ㄴ`·`ㄷ` 기본 모음 행을 각각 좁은 루프로 추가한다.
- 30음절의 표시·시범·표식·판정이 같은 template을 사용한다.
- 2340 × 1080에서 WritingCanvas 1962 × 954 px 이상과 글자별 정사각형 em 비율을 유지한다.
- 받침 6개는 이 마일스톤을 통과하기 전 노출하지 않는다.

완료 관문: 조립→쓰기→추천 복습이 연결되고 30음절의 정방향 수락·역방향과 잘못된 획순 거부가 통과한다.

### M4 — 실제 사용 검증과 로컬 릴리스

목표: 에뮬레이터에서 동작하는 앱과 실제 사용할 수 있는 앱을 구분해 마감한다.

- API 26과 API 36, 기준 2340 × 1080과 보조 가로 해상도에서 핵심 흐름을 검증한다.
- 홈→추천→쓰기→재시도·성공→다음→세션 완료→홈의 Android UI 계측 테스트를 추가한다.
- 그리기 중 p95 frame 32 ms 이하, 700 ms 이상 멈춤 0회를 목표로 측정한다.
- SM-S931N에서 콜드 시작 후 조작 가능 2초 이내와 50회 글자 이동의 크래시·멈춘 연출·지속 메모리 증가 없음 여부를 확인한다.
- 실제 대상 아이를 보호자 감독 아래 서로 다른 날 약 5분씩 3회 관찰한다.
- P0·P1 0개와 반복 진행을 막는 P2 0개 뒤 versionCode를 올리고 정식 서명 release APK의 서명·Manifest·업그레이드 설치·진도 보존을 확인한다.
- 로컬 APK 완성과 Play 등록·승인을 같은 상태로 표현하지 않는다.

완료 관문: 실제 아이 관찰과 정식 로컬 APK 검증이 모두 끝난다. 실제 관찰을 수행하지 못했다면 2차 제품 구현 완료와 실제 사용성 검증 완료를 분리해 보고한다.

## 성공 지표

원격 분석은 사용하지 않는다. 자동 측정, 기기 내부 요약, 보호자 감독 관찰만 사용한다.

### 자동·기기 지표

- 추천 세션 구성은 같은 진도 입력에서 항상 같은 결과를 낸다.
- 완료 이벤트는 한 세션·한 lesson에 중복 기록되지 않는다.
- 프로세스 종료·재부팅·업데이트 뒤 진도 보존 성공률 100%다.
- 원시 필기 좌표·개인정보·네트워크 전송 0건이다.
- P0·P1 0개, 반복 진행 방해 P2 0개다.

### 실제 아이 관찰 지표

- 첫 60초 동안 보호자가 대신 누르지 않은 상태에서 시작할 곳을 찾는다.
- 10초 안에 추천 카드 또는 시작점을 찾는다.
- 약 5분 안에 세 글자를 완료하거나 스스로 `집`을 선택한다.
- 자연스러운 재시도 뒤 활동을 중단하지 않고 다시 시작한다.
- 홈·다시쓰기·이전·다음과 세션 종료 두 동작을 글을 읽지 않고 구분한다.
- 세 번의 관찰에서 망설임, 무작위 탭, 보호자 도움, 재시도 뒤 행동, 자발적 계속 여부를 사실로 기록한다.

시간은 속도 점수가 아니라 장시간 멈춤을 찾는 관찰 기준이다. 아이가 천천히 하거나 스스로 끝내기를 선택한 것은 실패가 아니다.

## 구현 시작 전 결정할 두 항목

1. 정식 package namespace: 현재 `com.example.limdo`를 유지할지, 사용자가 소유한 namespace로 바꿀지 결정한다.
2. 보호자용 진도 백업: 기본안은 `android:allowBackup=false`인 완전 기기 내부 저장이다. OS 백업·복원이 필요하면 저장 범위와 복원 테스트를 별도 추가한다.

그 밖의 기획 기본값은 `무음`, `세 글자`, `모든 카드 잠금 없음`, `원격 기능 없음`, `실패 횟수 아이 화면 비노출`로 확정한다.

## 권장 첫 구현 루프

루프 181 후보: `로컬 완료 기록과 마지막 학습 이어가기`

- 분류: 제품 변경
- 사용자 가치: 앱을 다시 열어도 마지막 학습을 잃지 않고 다음에 연습할 글자를 찾을 수 있다.
- 최소 범위: 성공한 `lessonId`와 마지막 메뉴·lesson을 versioned 로컬 저장소에 기록하고, 홈의 마지막 메뉴와 선택 화면의 추천 한 글자를 한 번만 강조한다.
- 보존 범위: 현재 38개 글자와 네 조작은 모두 잠금 없이 유지하고 손글씨 원시 좌표를 저장하지 않는다.
- 성공 조건: 강제 종료·재실행·업데이트 뒤 이어하기, 중복 기록 방지, 손상 데이터 안전 복구, 새 권한·네트워크 0개, 자동·2340 × 1080 에뮬레이터·아이 대리 QA 통과.
- 중지 조건: 정식 `applicationId`와 백업 정책을 정하지 못했거나, 진도 저장이 현재 쓰기 입력 성능을 저하하면 구현을 시작하거나 완료하지 않는다.

이 루프를 완료한 뒤 세 글자 세션과 완료 화면을 별도 루프로 진행한다. 한 루프에서 진도 저장·전체 홈 재설계·보호자 화면·콘텐츠 확장을 한꺼번에 구현하지 않는다.
