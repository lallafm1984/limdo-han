## 수집 원칙

- 그래픽·시스템 완료 뒤 만들어진 같은 최종 commit·APK만 사용한다.
- 과거 루프 PNG·hierarchy를 재사용하지 않는다.
- 홈부터 실제 tap·draw·back·권한 응답·record·preview·delete 동작으로 진입한다.
- 각 고유 화면·중요 상태는 PNG, hierarchy, 진입 동작 로그와 1:1로 연결한다.
- 모든 PNG는 앱 영역 정확한 2340 × 1080이고 LimDo package가 전면 focus여야 한다.
- 데이터만 다른 동일 layout은 동등군을 선언할 수 있지만 모든 lesson의 진입·성공·다음 mapping 실행은 생략하지 않는다.
- 하나라도 실패하면 최종 판정을 통과로 바꾸지 않고 결함 수정 뒤 새 APK로 전량 다시 수집한다.

## 필수 화면·상태 inventory

### 아이 흐름

1. 홈 안정 상태와 세 메뉴 진입
2. 자음·모음·가나다 선택 화면과 홈 복귀
3. 현재 노출되는 모든 lesson의 초기 쓰기 화면
4. 현재 노출되는 모든 lesson의 실제 정방향 입력·성공 전체 화면·다음 mapping
5. 대표 geometry 동등군의 첫 획 뒤 진행 상태
6. 부정확 입력→실패 그림 없는 효과 시작·중간·끝→자동 재시작
7. 홈·다시쓰기·이전·다음의 초기·진행·성공·자동 진행 대기 상태
8. 보호자 목록이 없을 때의 자유 쓰기와 마지막→첫 순환

### 보호자 흐름

1. 보호자 전용 진입과 아이 화면 복귀
2. lesson 목록 없음·추가·중복·재정렬·삭제·처음부터·이어하기
3. `쓰기 전` 녹음 없음·권한 허용·녹음 중·완료·미리 듣기·다시 녹음·삭제
4. `정답 후` 녹음 없음·녹음 중·완료·미리 듣기·다시 녹음·삭제
5. 권한 거부·나중에 취소·손상 파일·저장 실패의 무음 대안
6. 녹음 전체 삭제와 진도 초기화의 분리

### 연결·수명주기

1. 쓰기 전 재생 1회→입력 허용
2. 정답 후 재생 1회→자동 다음 1회
3. 수동 네 조작이 재생·예약 자동 진행 취소
4. 목록 마지막의 완료 화면→홈·처음부터
5. background·화면 종료·audio focus 상실·앱 재실행
6. 앱 업데이트 뒤 목록 위치·설정·녹음 유지와 cloud/device-transfer 백업 0건
