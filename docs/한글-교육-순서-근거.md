# LimDo 한글 교육 순서 근거

조사일: 2026-08-26

이 문서는 LimDo의 수업 순서를 정할 때 참고할 공식 근거와 앱의 제품 결정을 구분해 기록한다. 공식 자료에 없는 세부 순서를 공식 교육과정이라고 표현하지 않는다.

## 확인한 공식 근거

### 1. 자음 다음 모음, 그다음 글자 조합

교육부의 한글 책임교육 소개 자료는 초등학교 1학년 국어 교과서의 큰 순서를 `연필잡기 → 자음 → 모음 → 글자의 짜임 → 받침 없는 글자 → 받침 있는 글자 → 겹받침`으로 설명한다.

- 근거: [교육부 월간 교육 2019년 11월호, 25쪽](https://www.moe.go.kr/upload/brochureBoard/1/2019/11/1574381420882_2468889902779639.pdf)
- LimDo 적용: 손가락 준비 활동은 관찰 과제에 두고, 제품 수업은 `자음 → 모음 → 자음과 모음의 조합 → 받침 없는 글자` 순서로 확장한다.

### 2. 첫 기본 자음은 ㄱ, ㄴ, ㄷ이고 첫 기본 모음은 ㅏ

국립국어원이 인용한 한글 맞춤법 제4항의 기본 자모 순서는 자음 `ㄱ, ㄴ, ㄷ, ㄹ…`, 모음 `ㅏ, ㅑ, ㅓ, ㅕ…`이다.

- 근거: [국립국어원 온라인가나다, 한글 자모의 순서와 이름](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=310629)
- LimDo 적용: 첫 자음 묶음은 `ㄱ → ㄴ → ㄷ`, 다음 좁은 묶음은 `ㄹ → ㅁ → ㅂ`, 세 번째 묶음은 `ㅅ → ㅇ → ㅈ`, 네 번째 묶음은 `ㅊ → ㅋ → ㅌ`, 마지막 기본 자음 묶음은 `ㅍ → ㅎ`로 확장한다. 모음은 표준 자모 순서에서 `ㅏ` 다음에 오는 `ㅐ`를 빠뜨리지 않고 `ㅏ → ㅐ → ㅑ → ㅓ → ㅕ` 순으로 확장한다.
- 주의: 맞춤법의 자모 순서는 사전·표기의 기본 순서이며, 이것만으로 모든 아동에게 하나의 수업 순서가 강제된다는 뜻은 아니다.

### 3. 놀이나 활동 중심, 수준별 관찰과 후속 학습

교육부 자료는 한글을 놀이나 활동으로 익히도록 구성하고, 초기에는 무리한 받아쓰기·알림장·일기 쓰기를 지양하며, 학습 뒤 진단과 개별 후속 학습을 연결한다.

- 근거: [교육부, 초등학교 한글 책임지고 교육하다](https://www.moe.go.kr/boardCnts/view.do?boardID=294&boardSeq=78651&lev=0&m=0204&opType=N&s=moe)
- LimDo 적용: 글을 읽어야만 진행하는 지시, 점수 압박, 받아쓰기를 첫 묶음에 넣지 않는다. 큰 쓰기판, 움직이는 시범, 한국어 음성, 자동차 보상으로 진행하고 관찰 결과에 따라 속도와 반복을 조정한다.

## LimDo 첫 학습 묶음의 제품 결정

첫 묶음은 다음 순서로 고정한다.

`ㄱ → ㄴ → ㄷ → ㅏ → 가 → 나 → 다`

이 결정의 이유는 다음과 같다.

1. 공식 자료의 큰 순서인 자음 다음 모음을 따른다.
2. 기본 자음 순서의 앞 세 글자 `ㄱ, ㄴ, ㄷ`을 먼저 익힌다.
3. 첫 기본 모음 `ㅏ`를 익힌 뒤 이미 본 자음과 결합한다.
4. 사용자가 지정한 기본 조합 순서 `가 → 나 → 다`로 즉시 연결한다.

`가 → 나 → 다` 자체를 교육부가 유일한 세부 수업 순서로 지정했다는 근거는 확인하지 못했다. 이는 공식 큰 순서와 자모 순서에 맞춘 LimDo의 첫 제품 묶음이며, 실제 아이 관찰 결과에 따라 반복 횟수와 한 번에 제시할 글자 수를 조정한다.

## 첫 묶음의 쓰기 template

아래 획 구분은 LimDo가 화면 시범과 판정을 일치시키기 위해 사용하는 교육용 제품 계약이다. 공식 자료가 모든 글꼴 모양과 획 분할을 하나로 강제한다고 주장하지 않는다.

### 시스템 고딕 자형 기준

최신 사용자 지시의 “Codex에서 보이는 폰트 모양”을 글자 외형 기준으로 반영하기 위해 macOS 시스템 한글 고딕체 `Apple SD Gothic Neo`의 자모를 대조했다. 앱은 글꼴 파일의 외곽선을 그대로 판정하지 않고, 다음 외형을 쓰기 순서가 있는 중심선 template으로 재구성한다.

- `ㅂ`: 위를 열고 두 세로획을 가운데와 아래 가로획으로 연결한다.
- `ㅅ·ㅈ·ㅊ`: 중앙의 짧은 세로 흐름에서 양쪽으로 자연스럽게 벌어지는 곡선형을 쓴다.
- `ㅐ`: 왼쪽 세로획과 오른쪽 세로획 사이를 가운데 가로획으로 연결한다.
- `ㅌ`: 왼쪽 세로획과 위·가운데·아래 가로획으로 이루어진 E형을 쓴다.
- `ㅍ`: 긴 위·아래 가로획 사이에 짧은 두 세로획을 둔다.
- `ㅎ`: 짧은 위 가로획, 긴 가운데 가로획, 그 아래와 분리된 넓은 타원을 둔다.

보이는 guide는 둥근 끝의 선분 조각을 여러 개 겹치지 않고, 획 하나를 하나의 path로 그린다. 표시·동적 안내·입력 판정은 이 같은 template을 공유한다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 1 | ㄱ | 1 | 오른쪽, 꺾어서 아래쪽 |
| 2 | ㄴ | 1 | 아래쪽, 꺾어서 오른쪽 |
| 3 | ㄷ | 2 | 위쪽 가로획 / 왼쪽에서 아래로 내려가 바닥을 오른쪽으로 |
| 4 | ㅏ | 2 | 세로획 아래쪽 / 가운데에서 오른쪽 |
| 5 | 가 | 3 | ㄱ 1획 + ㅏ 2획 |
| 6 | 나 | 3 | ㄴ 1획 + ㅏ 2획 |
| 7 | 다 | 4 | ㄷ 2획 + ㅏ 2획 |

### 다음 기본 자음 묶음의 쓰기 template

국립국어원의 한글 맞춤법 근거는 `ㄹ → ㅁ → ㅂ`의 기본 자모 순서를 뒷받침하지만, 앱에서 손가락으로 이어 쓰기 위한 획 분할까지 규정하지는 않는다. 아래 획 구분은 기존 LimDo의 꺾인 선을 한 번에 잇는 방식과 표시·판정 일치를 유지하기 위한 제품 결정이다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 4 | ㄹ | 3 | 위 가로와 오른쪽 세로 / 가운데를 왼쪽으로 / 왼쪽 아래와 바닥을 오른쪽으로 |
| 5 | ㅁ | 3 | 왼쪽 세로 / 위와 오른쪽 세로 / 아래 가로 |
| 6 | ㅂ | 4 | 왼쪽 세로 / 오른쪽 세로 / 가운데 가로 / 아래 가로 |

### 세 번째 기본 자음 묶음의 쓰기 template

국립국어원이 인용한 한글 맞춤법 제4항은 `ㅂ → ㅅ → ㅇ → ㅈ`의 기본 자모 순서를 뒷받침한다. 다만 해당 규정은 손가락 쓰기의 획 분할과 곡선 표본을 규정하지 않는다. 아래 획 수·방향·모양은 표시·동적 안내·판정을 하나의 template에서 파생시키는 LimDo 제품 결정이다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 7 | ㅅ | 2 | 가운데에서 곡선으로 왼쪽 아래 / 곡선으로 오른쪽 아래 |
| 8 | ㅇ | 1 | 위 가운데에서 오른쪽으로 돌아 동그라미를 닫기 |
| 9 | ㅈ | 3 | 위 가로획 / 가운데에서 곡선으로 왼쪽 아래 / 곡선으로 오른쪽 아래 |

모든 글자는 같은 정사각형 em 안에서 자모 비율을 보존하고, 보이는 guide와 입력 판정이 같은 template을 사용한다. 성공 자동차 이동 칸 수도 위 획수와 같아야 한다.

### 네 번째 기본 자음 묶음의 쓰기 template

국립국어원이 인용한 한글 맞춤법 제4항은 `ㅈ → ㅊ → ㅋ → ㅌ`의 기본 자모 순서를 뒷받침한다. 국립국어원 「한글 글자 모양의 정비」는 `ㅈ·ㅊ·ㅌ`에 실제 자형과 획수 변형이 있음을 설명하며, 교육 자료에서 설명하는 쓰기 방법과 연습 글자 모양이 달라지면 혼란을 줄 수 있다고 지적한다. 자형 변형은 있지만 LimDo는 한 수업 안에서 보이는 모양과 쓰기 순서를 바꾸지 않는다.

- 근거: [국립국어원, 한글 글자 모양의 정비](https://www.korean.go.kr/nkview/news/9/8.htm)
- 참고 표본: [누리 세종학당, 세종한국어 1](https://nuri.iksi.or.kr/front/cms/contents/layout2/learningsejong/detail.do?csCmsMastrSeq=2151&menuSn=651)
- LimDo 선택: 공식 자료가 하나의 손글씨 자형만을 강제한다고 과장하지 않는다. 최신 사용자가 지정한 시스템 고딕 기준으로 `ㅈ`은 가로획과 두 곡선 다리, `ㅊ`은 짧은 위 가로획·긴 아래 가로획·두 곡선 다리, `ㅌ`은 E형으로 고정한다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 10 | ㅊ | 4 | 짧은 위 가로획 / 긴 아래 가로획 / 왼쪽 곡선 다리 / 오른쪽 곡선 다리 |
| 11 | ㅋ | 2 | 위 가로와 오른쪽 세로 / 가운데 가로획 |
| 12 | ㅌ | 3 | 위 가로획 / 가운데 가로획 / 왼쪽 세로와 아래 가로획 |

세 글자도 같은 정사각형 em template에서 guide·동적 안내·판정을 함께 파생하며 자동차는 각각 4·2·3칸 이동한다.

| 14 | ㅎ | 3 | 짧은 위 가로 / 긴 가운데 가로 / 아래에 떨어진 넓은 타원 닫기 |

### 다음 기본 모음 묶음의 쓰기 template

국립국어원이 안내한 한글 자모의 전체 순서에서 `ㅐ`는 `ㅏ` 다음에 온다. LimDo는 기존에 누락한 `ㅐ`를 모음 첫부분에 추가하고, 이후 기존 모음 순서를 유지한다. 획 분할과 화면 비율은 LimDo 제품 결정이다.

| 3 | ㅑ | 3 | 세로획 아래쪽 / 위 짧은 가로획 오른쪽 / 아래 짧은 가로획 오른쪽 |
| 3 | ㅓ | 2 | 세로획 아래쪽 / 가운데에서 왼쪽 |
| 4 | ㅕ | 3 | 세로획 아래쪽 / 위 짧은 가로획 왼쪽 / 아래 짧은 가로획 왼쪽 |
| 5 | ㅗ | 2 | 긴 가로획 오른쪽 / 가운데 세로획 위쪽 |
| 6 | ㅛ | 3 | 긴 가로획 오른쪽 / 왼쪽 짧은 세로획 위쪽 / 오른쪽 짧은 세로획 위쪽 |
| 7 | ㅜ | 2 | 긴 가로획 오른쪽 / 가운데 세로획 아래쪽 |

| 9 | ㅡ | 1 | 긴 가로획 오른쪽 |
| 10 | ㅣ | 1 | 긴 세로획 아래쪽 |

아홉 글자도 정사각형 em 안에서 고유 모양과 좌우·상하 방향을 보존하며, guide·동적 안내·판정은 같은 template을 사용한다. `ㅗ·ㅛ·ㅜ`의 성공 자동차는 각각 2·3·2칸, `ㅠ·ㅡ·ㅣ`는 각각 3·1·1칸 이동한다.

### 첫 받침 없는 글자 묶음의 쓰기 template

교육부 자료의 큰 흐름은 `글자의 짜임 → 받침 없는 글자` 단계를 뒷받침한다. `라 → 마 → 바`의 세부 순서와 아래 획 분할은 이미 익힌 기본 자음 `ㄹ·ㅁ·ㅂ`과 모음 `ㅏ`를 차례로 결합하는 LimDo 제품 결정이며, 교육부가 이 세 글자의 유일한 순서를 지정했다고 표현하지 않는다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 1 | 라 | 5 | ㄹ 3획 + ㅏ 2획 |
| 2 | 마 | 5 | ㅁ 3획 + ㅏ 2획 |
| 3 | 바 | 6 | ㅂ 4획 + ㅏ 2획 |

세 글자는 정사각형 em의 왼쪽에 자음, 오른쪽에 `ㅏ`를 놓아 조합 비율을 보존한다. guide·동적 안내·판정은 같은 template을 사용하고 자동차는 각각 5·5·6칸 이동한다.

### 두 번째 받침 없는 글자 묶음의 쓰기 template

세 글자는 정사각형 em의 왼쪽에 자음, 오른쪽에 `ㅏ`를 놓아 조합 비율을 보존한다. guide·동적 안내·판정은 같은 template을 사용하고 자동차는 각각 4·3·5칸 이동한다.

### 세 번째 받침 없는 글자 묶음의 쓰기 template

교육부 자료는 `글자의 짜임 → 받침 없는 글자`라는 단계 흐름을 뒷받침한다. `차 → 카 → 타`의 세부 순서와 획 분할은 이미 익힌 기본 자음 `ㅊ·ㅋ·ㅌ`과 모음 `ㅏ`를 차례로 결합하는 LimDo 제품 결정이며, 교육부가 이 세 글자의 유일한 순서나 획수를 지정했다고 표현하지 않는다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 7 | 차 | 6 | ㅊ 4획 + ㅏ 2획 |
| 8 | 카 | 4 | ㅋ 2획 + ㅏ 2획 |
| 9 | 타 | 5 | ㅌ 3획 + ㅏ 2획 |

세 글자는 정사각형 em의 왼쪽에 자음, 오른쪽에 `ㅏ`를 놓아 조합 비율을 보존한다. guide·동적 안내·판정은 같은 template을 사용하고 자동차는 각각 6·4·5칸 이동한다.

## 다음 확장 원칙

첫 묶음을 검증한 뒤 한 번에 하나의 좁은 묶음만 추가한다.

| 교육부 흐름 | LimDo 단계 계약 | 현재 상태 |
|---|---|---|
| 연필잡기와 선 긋기 | `PENCIL_PREPARATION` | 손가락 준비 관찰 과제로 분리, 수업 미구현 |
| 자음 | `CONSONANTS` | 기본 자음 `ㄱ → ㄴ → ㄷ → ㄹ → ㅁ → ㅂ → ㅅ → ㅇ → ㅈ → ㅊ → ㅋ → ㅌ → ㅍ → ㅎ` 구현 |
| 모음 | `VOWELS` | `ㅏ → ㅐ → ㅑ → ㅓ → ㅕ → ㅗ → ㅛ → ㅜ → ㅠ → ㅡ → ㅣ` 구현 |
| 글자의 짜임 | `SYLLABLE_STRUCTURE` | 이미 배운 자모로 `가 → 나 → 다` 구현 |
| 받침 없는 글자 | `OPEN_SYLLABLES` | `라 → 마 → 바 → 사 → 아 → 자 → 차 → 카 → 타` 구현 |
| 받침 있는 글자 | `FINAL_CONSONANTS` | 앞 단계 검증 뒤 확장 |
| 겹받침 | `DOUBLE_FINAL_CONSONANTS` | 마지막 단계 후보 |

코드의 `KoreanCurriculum.educationFlow`도 위 단계 순서를 고정한다. 첫 묶음을 검증한 뒤에는 나머지 기본 자음, 나머지 기본 모음, 받침 없는 글자 순으로 한 단계씩 추가한다.

다음 단계는 현재 묶음의 자동 검증뿐 아니라 실제 관찰 기록에서 막힘이 없는지 확인한 뒤 결정한다. 무리한 반복이나 이미 통과한 화면의 근거 재수집은 새 학습 진전으로 간주하지 않는다.
