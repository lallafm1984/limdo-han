# LimDo 한글 교육 순서 근거

조사일: 2026-08-26

이 문서는 LimDo의 수업 순서를 정할 때 참고할 공식 근거와 앱의 제품 결정을 구분해 기록한다. 공식 자료에 없는 세부 순서를 공식 교육과정이라고 표현하지 않는다.

## 확인한 공식 근거

### 1. 자음 다음 모음, 그다음 글자 조합

교육부의 한글 책임교육 소개 자료는 초등학교 1학년 국어 교과서의 큰 순서를 `연필잡기 → 자음 → 모음 → 글자의 짜임 → 받침 없는 글자 → 받침 있는 글자 → 겹받침`으로 설명한다.

- 근거: [교육부 월간 교육 2019년 11월호, 25쪽](https://www.moe.go.kr/upload/brochureBoard/1/2019/11/1574381420882_2468889902779639.pdf)
- LimDo 적용: 손가락 준비 활동은 관찰 과제에 두고, 제품 수업은 `자음 → 모음 → 자음과 모음의 조합 → 받침 없는 글자` 순서로 확장한다.

### 2. 첫 기본 자음은 ㄱ, ㄴ, ㄷ이고 첫 기본 모음은 ㅏ

국립국어원이 인용한 한글 맞춤법 제4항의 기본 자모 순서는 자음 `ㄱ, ㄴ, ㄷ, ㄹ…`, 모음 `ㅏ, ㅑ, ㅓ, ㅕ…`이다.

- 근거: [국립국어원 온라인가나다, 한글 자모의 순서와 이름](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=310629)
- LimDo 적용: 첫 자음 묶음은 `ㄱ → ㄴ → ㄷ`, 다음 좁은 묶음은 `ㄹ → ㅁ → ㅂ`, 세 번째 묶음은 `ㅅ → ㅇ → ㅈ`, 네 번째 묶음은 `ㅊ → ㅋ → ㅌ`, 마지막 기본 자음 묶음은 `ㅍ → ㅎ`로 확장한다.
- 주의: 맞춤법의 자모 나열 순서는 사전·표기의 기준이지 초기 읽기 수업 순서가 아니다. 따라서 맞춤법 순서만 근거로 `ㅏ → ㅐ → ㅑ`를 초기 모음 교육 순서로 고정하지 않는다.

### 3. 놀이나 활동 중심, 수준별 관찰과 후속 학습

교육부 자료는 한글을 놀이나 활동으로 익히도록 구성하고, 초기에는 무리한 받아쓰기·알림장·일기 쓰기를 지양하며, 학습 뒤 진단과 개별 후속 학습을 연결한다.

- 근거: [교육부, 초등학교 한글 책임지고 교육하다](https://www.moe.go.kr/boardCnts/view.do?boardID=294&boardSeq=78651&lev=0&m=0204&opType=N&s=moe)
- LimDo 적용: 글을 읽어야만 진행하는 지시, 점수 압박, 받아쓰기를 첫 묶음에 넣지 않는다. 큰 쓰기판, 움직이는 시범, 한국어 음성, 자동차 보상으로 진행하고 관찰 결과에 따라 속도와 반복을 조정한다.

### 4. 기본 모음과 받침 없는 글자의 세부 연습 순서

교육부 자료는 `글자의 짜임` 뒤 `받침 없는 글자`로 이어지는 큰 단계를 제시하지만, 모든 초성·모음 조합의 유일한 세부 순서를 지정하지는 않는다. 교육 현장에서 사용하는 기초 진단 자료는 모음·자음·받침 없는 글자·받침 없는 단어를 구분하고, 복잡한 모음과 받침을 뒤 단계에서 확인한다.

- 근거: [경기도교육청, 한글 해득 수준 진단 자료](https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202202040750175820.pdf)
- LimDo 기본 모음 계약: `ㅏ → ㅑ → ㅓ → ㅕ → ㅗ → ㅛ → ㅜ → ㅠ → ㅡ → ㅣ`.
- LimDo 받침 없는 글자 계약: 초성을 고정하고 위 기본 모음만 순서대로 바꾼다. 첫 행은 `가 → 갸 → 거 → 겨 → 고 → 교 → 구 → 규 → 그 → 기`, 다음 행은 `나 → 냐 → 너 → 녀 → 노 → 뇨 → 누 → 뉴 → 느 → 니`, 그 다음은 `다 → 댜 → 더 → 뎌 → 도 → 됴 → 두 → 듀 → 드 → 디`이다.
- `ㅐ` 처리: 앱에 이미 구현된 `ㅐ` 자모 수업은 삭제하지 않는다. 다만 첫 기본 모음 행에서는 제외하고, 기본 모음과 받침 없는 글자 연습 뒤 복잡한 모음 단계에서 `개·내·대` 같은 조합으로 확장한다.

위 음절 행은 교육부가 유일한 순서로 지정한 것이 아니라, 공식 큰 단계와 기초 진단의 난이도 구분을 따르면서 아이가 한 번에 바뀌는 요소를 모음 하나로 제한하기 위한 LimDo 제품 결정이다.

## LimDo 첫 학습 묶음의 제품 결정

첫 묶음은 다음 순서로 고정한다.

`ㄱ → ㄴ → ㄷ → ㅏ → 가 → 나 → 다`

이 결정의 이유는 다음과 같다.

1. 공식 자료의 큰 순서인 자음 다음 모음을 따른다.
2. 기본 자음 순서의 앞 세 글자 `ㄱ, ㄴ, ㄷ`을 먼저 익힌다.
3. 첫 기본 모음 `ㅏ`를 익힌 뒤 이미 본 자음과 결합한다.
4. 사용자가 지정한 기본 조합 순서 `가 → 나 → 다`로 즉시 연결한다.

`가 → 나 → 다` 자체를 교육부가 유일한 세부 수업 순서로 지정했다는 근거는 확인하지 못했다. 이는 공식 큰 순서와 자모 순서에 맞춘 LimDo의 첫 제품 묶음이며, 실제 아이 관찰 결과에 따라 반복 횟수와 한 번에 제시할 글자 수를 조정한다.

## 첫 묶음의 쓰기 template

아래 획 구분은 LimDo가 화면 시범과 판정을 일치시키기 위해 사용하는 교육용 제품 계약이다. 공식 자료가 모든 글꼴 모양과 획 분할을 하나로 강제한다고 주장하지 않는다.

### 시스템 고딕 자형 기준

최신 사용자 지시의 “Codex에서 보이는 폰트 모양”을 글자 외형 기준으로 반영하기 위해 macOS 시스템 한글 고딕체 `Apple SD Gothic Neo`의 자모를 대조했다. 앱은 글꼴 파일의 외곽선을 그대로 판정하지 않고, 다음 외형을 쓰기 순서가 있는 중심선 template으로 재구성한다.

- `ㅂ`: 위를 열고 두 세로획을 가운데와 아래 가로획으로 연결한다.
- `ㅅ·ㅈ·ㅊ`: 중앙의 짧은 세로 흐름에서 양쪽으로 자연스럽게 벌어지는 곡선형을 쓴다.
- `ㅐ`: 왼쪽 세로획과 오른쪽 세로획 사이를 가운데 가로획으로 연결한다.
- `ㅌ`: 왼쪽 세로획과 위·가운데·아래 가로획으로 이루어진 E형을 쓴다.
- `ㅍ`: 긴 위·아래 가로획 사이에 짧은 두 세로획을 둔다.
- `ㅎ`: 짧은 위 가로획, 긴 가운데 가로획, 그 아래와 분리된 넓은 타원을 둔다.

보이는 guide는 둥근 끝의 선분 조각을 여러 개 겹치지 않고, 획 하나를 하나의 path로 그린다. 표시·동적 안내·입력 판정은 이 같은 template을 공유한다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 1 | ㄱ | 1 | 오른쪽, 꺾어서 아래쪽 |
| 2 | ㄴ | 1 | 아래쪽, 꺾어서 오른쪽 |
| 3 | ㄷ | 2 | 위쪽 가로획 / 왼쪽에서 아래로 내려가 바닥을 오른쪽으로 |
| 4 | ㅏ | 2 | 세로획 아래쪽 / 가운데에서 오른쪽 |
| 5 | 가 | 3 | ㄱ 1획 + ㅏ 2획 |
| 6 | 나 | 3 | ㄴ 1획 + ㅏ 2획 |
| 7 | 다 | 4 | ㄷ 2획 + ㅏ 2획 |

### 다음 기본 자음 묶음의 쓰기 template

국립국어원의 한글 맞춤법 근거는 `ㄹ → ㅁ → ㅂ`의 기본 자모 순서를 뒷받침하지만, 앱에서 손가락으로 이어 쓰기 위한 획 분할까지 규정하지는 않는다. 아래 획 구분은 기존 LimDo의 꺾인 선을 한 번에 잇는 방식과 표시·판정 일치를 유지하기 위한 제품 결정이다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 4 | ㄹ | 3 | 위 가로와 오른쪽 세로 / 가운데를 왼쪽으로 / 왼쪽 아래와 바닥을 오른쪽으로 |
| 5 | ㅁ | 3 | 왼쪽 세로 / 위와 오른쪽 세로 / 아래 가로 |
| 6 | ㅂ | 4 | 왼쪽 세로 / 오른쪽 세로 / 가운데 가로 / 아래 가로 |

### 세 번째 기본 자음 묶음의 쓰기 template

국립국어원이 인용한 한글 맞춤법 제4항은 `ㅂ → ㅅ → ㅇ → ㅈ`의 기본 자모 순서를 뒷받침한다. 다만 해당 규정은 손가락 쓰기의 획 분할과 곡선 표본을 규정하지 않는다. 아래 획 수·방향·모양은 표시·동적 안내·판정을 하나의 template에서 파생시키는 LimDo 제품 결정이다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 7 | ㅅ | 2 | 가운데에서 곡선으로 왼쪽 아래 / 곡선으로 오른쪽 아래 |
| 8 | ㅇ | 1 | 위 가운데에서 오른쪽으로 돌아 동그라미를 닫기 |
| 9 | ㅈ | 3 | 위 가로획 / 가운데에서 곡선으로 왼쪽 아래 / 곡선으로 오른쪽 아래 |

모든 글자는 같은 정사각형 em 안에서 자모 비율을 보존하고, 보이는 guide와 입력 판정이 같은 template을 사용한다. 성공 자동차 이동 칸 수도 위 획수와 같아야 한다.

### 네 번째 기본 자음 묶음의 쓰기 template

국립국어원이 인용한 한글 맞춤법 제4항은 `ㅈ → ㅊ → ㅋ → ㅌ`의 기본 자모 순서를 뒷받침한다. 국립국어원 「한글 글자 모양의 정비」는 `ㅈ·ㅊ·ㅌ`에 실제 자형과 획수 변형이 있음을 설명하며, 교육 자료에서 설명하는 쓰기 방법과 연습 글자 모양이 달라지면 혼란을 줄 수 있다고 지적한다. 자형 변형은 있지만 LimDo는 한 수업 안에서 보이는 모양과 쓰기 순서를 바꾸지 않는다.

- 근거: [국립국어원, 한글 글자 모양의 정비](https://www.korean.go.kr/nkview/news/9/8.htm)
- 참고 표본: [누리 세종학당, 세종한국어 1](https://nuri.iksi.or.kr/front/cms/contents/layout2/learningsejong/detail.do?csCmsMastrSeq=2151&menuSn=651)
- LimDo 선택: 공식 자료가 하나의 손글씨 자형만을 강제한다고 과장하지 않는다. 최신 사용자가 지정한 시스템 고딕 기준으로 `ㅈ`은 가로획과 두 곡선 다리, `ㅊ`은 짧은 위 가로획·긴 아래 가로획·두 곡선 다리, `ㅌ`은 E형으로 고정한다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 10 | ㅊ | 4 | 짧은 위 가로획 / 긴 아래 가로획 / 왼쪽 곡선 다리 / 오른쪽 곡선 다리 |
| 11 | ㅋ | 2 | 위 가로와 오른쪽 세로 / 가운데 가로획 |
| 12 | ㅌ | 3 | 위 가로획 / 가운데 가로획 / 왼쪽 세로와 아래 가로획 |

세 글자도 같은 정사각형 em template에서 guide·동적 안내·판정을 함께 파생하며 자동차는 각각 4·2·3칸 이동한다.

### 남은 기본 자음 묶음의 쓰기 template

국립국어원이 인용한 한글 맞춤법 제4항은 `ㅌ → ㅍ → ㅎ`의 기본 자모 순서를 뒷받침한다. 해당 규정은 손가락 쓰기의 획 분할과 원형 표본을 정하지 않으므로 아래 내용은 LimDo 제품 결정이다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 13 | ㅍ | 4 | 위 긴 가로 / 아래 긴 가로 / 왼쪽 짧은 세로 / 오른쪽 짧은 세로 |
| 14 | ㅎ | 3 | 짧은 위 가로 / 긴 가운데 가로 / 아래에 떨어진 넓은 타원 닫기 |

두 글자도 같은 정사각형 em template에서 guide·동적 안내·판정을 함께 파생하며 자동차는 각각 4·3칸 이동한다.

### 기본 모음과 이후 `ㅐ`의 쓰기 template

초기 기본 모음 교육 순서는 `ㅏ → ㅑ → ㅓ → ㅕ → ㅗ → ㅛ → ㅜ → ㅠ → ㅡ → ㅣ`로 사용한다. `ㅐ` template은 이미 구현돼 있으므로 보존하되, 맞춤법 나열 순서와 초기 수업 순서를 혼동하지 않고 복잡한 모음 단계에서 조합 글자로 확장한다. 획 분할과 화면 비율은 LimDo 제품 결정이다.

| 순서 | 글자 | LimDo 획수 | 화면 시범 |
|---:|:---:|---:|---|
| 2 | ㅑ | 3 | 세로획 아래쪽 / 위 짧은 가로획 오른쪽 / 아래 짧은 가로획 오른쪽 |
| 3 | ㅓ | 2 | 세로획 아래쪽 / 가운데에서 왼쪽 |
| 4 | ㅕ | 3 | 세로획 아래쪽 / 위 짧은 가로획 왼쪽 / 아래 짧은 가로획 왼쪽 |
| 5 | ㅗ | 2 | 긴 가로획 오른쪽 / 가운데 세로획 위쪽 |
| 6 | ㅛ | 3 | 긴 가로획 오른쪽 / 왼쪽 짧은 세로획 위쪽 / 오른쪽 짧은 세로획 위쪽 |
| 7 | ㅜ | 2 | 긴 가로획 오른쪽 / 가운데 세로획 아래쪽 |
| 8 | ㅠ | 3 | 긴 가로획 오른쪽 / 왼쪽 짧은 세로획 아래쪽 / 오른쪽 짧은 세로획 아래쪽 |
| 9 | ㅡ | 1 | 긴 가로획 오른쪽 |
| 10 | ㅣ | 1 | 긴 세로획 아래쪽 |
| 이후 | ㅐ | 3 | 왼쪽 세로획 아래쪽 / 가운데 가로획 오른쪽 / 오른쪽 세로획 아래쪽 |

아홉 글자도 정사각형 em 안에서 고유 모양과 좌우·상하 방향을 보존하며, guide·동적 안내·판정은 같은 template을 사용한다. `ㅗ·ㅛ·ㅜ`의 성공 자동차는 각각 2·3·2칸, `ㅠ·ㅡ·ㅣ`는 각각 3·1·1칸 이동한다.

### 첫 받침 없는 글자 묶음의 쓰기 template

| 1 | 라 | 5 | ㄹ 3획 + ㅏ 2획 |

| 3 | 바 | 6 | ㅂ 4획 + ㅏ 2획 |

## 받침 있는 음절의 조합 비율

### 공식 원리와 교육 자료에서 확인한 사실

- 국립국어원은 한글 음절이 초성·중성·종성의 자리로 구성되며, 자모를 음절 단위로 모아 쓴다고 설명한다. 받침 있는 글자는 받침 없는 글자에 종성만 덧붙인 긴 모양이 아니라 한 정사각형 음절 안의 세 자리를 다시 구성한 글자다.
  - 근거: [국립국어원, 한글의 구성 원리](https://www.korean.go.kr/hangeul/principle/001.html)
- 국립한글박물관은 한글 활자에서 같은 자모도 놓이는 위치에 따라 크기와 모양이 미세하게 달라진다고 설명한다. 초성·중성·종성을 각각 한 모양으로 고정하면 음절의 균형을 보존하기 어렵다는 뜻이다.
  - 근거: [국립한글박물관, 한글과 근대 과학 기술의 만남](https://www.hangeul.go.kr/webzine/202308/sub2_2.html)
- 국립국어원 글꼴 연구는 받침 없는 세로 모음 음절을 `좌우` 자리, 받침 있는 음절을 `좌우하` 자리로 구분하고 윤곽·공간·위치·균형을 함께 분석한다.
  - 근거: [국립국어원, 한글 글꼴 변천에 나타난 글자꼴 구조 연구](https://www.korean.go.kr/nkview/nklife/2013_3/23_03.pdf)
- 교육청 기초 한글 자료 `찬찬한글`은 `가·나·다` 같은 받침 없는 글자 아래에 `ㄱ·ㄴ·ㄹ·ㄷ` 등의 받침을 별도 자리로 결합해 연습하게 한다. 이는 초·중성 윗칸과 종성 아랫칸을 아이가 시각적으로 구별해야 한다는 교육 화면 근거다.
  - 근거: [제주특별자치도교육청, 찬찬한글 학생용](https://www.jje.go.kr/board/view.jje?boardId=BBS_0000617&dataSid=1119815&menuCd=DOM_000000104001015000)

공식 자료는 모든 글자의 수치 좌표를 하나로 지정하지 않는다. 따라서 아래 좌표는 공식 표준이 아니라, 위 조합 원리를 지키면서 시스템 고딕체 `Apple SD Gothic Neo`와 `AppleGothic`의 `가·각·간·갇·갈·감·갑` 외곽 비율을 비교해 정한 LimDo의 교육용 중심선 계약이다.

### LimDo 조합 등급

받침 6글자가 상단의 동일한 `가` template을 공유하던 방식을 폐기한다. 종성 모양이 차지하는 높이에 따라 윗칸 초·중성과 아랫칸 종성의 비율을 함께 바꾼다.

| 조합 등급 | 첫 적용 글자 | 윗칸 특징 | 종성 중심선 특징 |
|---|---|---|---|
| 보통 받침 | `각·갇·감` | 초성 아래 `0.50em`, 중성 아래 `0.52em` | 종성 위 `0.66em` |
| 낮은 받침 | `간` | 단순한 `ㄴ` 받침 위의 윗칸을 `0.54~0.56em`까지 사용 | 종성 위 `0.70em` |
| 높이를 많이 쓰는 받침 | `갈·갑` | 복잡한 종성을 위해 초·중성 아래를 `0.48em`으로 제한 | `갈`은 `0.62~0.88em`, `갑`은 `0.63~0.88em` |

`갈`의 교육용 비율은 다음과 같이 고정한다.

- 초성 `ㄱ`: `x 0.12~0.50em`, `y 0.12~0.48em`
- 중성 `ㅏ`: 세로축 `x 0.70em`, `y 0.12~0.48em`, 가지 `y 0.27em`
- 종성 `ㄹ`: `x 0.20~0.80em`, 세 층 `y 0.62·0.75·0.88em`
- 받침 글자 guide 굵기: `0.12em`; `갈`의 윗칸과 종성 중심선 사이 간격은 `0.14em`

굵기까지 포함한 `갈`의 실제 흰색 외곽은 정사각형 em의 대략 `x 0.06~0.92em`, `y 0.06~0.94em` 안에 있어야 한다. 중심선 좌표만 0~1 범위에 두고 굵은 guide 외곽이 정사각형 밖으로 나가는 경우는 통과로 인정하지 않는다.

### 원형 획과 조합 글자 겹침

- `ㅇ`과 `ㅎ`의 원형은 위에서 시작해 왼쪽으로 진행하는 반시계 방향을 LimDo 교육용 계약으로 사용한다. 기본 `ㅇ·ㅎ`과 조합 `아·하`는 같은 원형 중심선, 방향 metadata, 음성 안내와 판정을 공유한다.
- `파`의 초성 `ㅍ`은 왼쪽 조합 칸에서 두 세로획의 중심 간격을 guide 굵기보다 크게 유지한다. 굵은 guide를 사용해도 두 세로획이 하나의 흰색 덩어리로 합쳐져서는 안 된다.

이 계약은 `가` 전체를 비균일하게 찌그러뜨리는 것이 아니다. 정사각형 em 안에서 각 자모의 가로·세로 비율을 보존하며, 음절의 자리에 맞는 별도 초성·중성·종성 중심선을 사용한다. 표시·동적 획 안내·손가락 입력 판정은 반드시 같은 template에서 파생한다. 앞으로 받침을 추가할 때도 종성 하나를 공통 `가` 아래에 붙이지 않고, 실제 자형과 교육 자료를 대조해 조합 등급을 먼저 결정한다.

## 다음 확장 원칙

첫 묶음을 검증한 뒤 한 번에 하나의 좁은 묶음만 추가한다.

| 교육부 흐름 | LimDo 단계 계약 | 현재 상태 |
|---|---|---|
| 연필잡기와 선 긋기 | `PENCIL_PREPARATION` | 손가락 준비 관찰 과제로 분리, 수업 미구현 |
| 자음 | `CONSONANTS` | 기본 자음 `ㄱ → ㄴ → ㄷ → ㄹ → ㅁ → ㅂ → ㅅ → ㅇ → ㅈ → ㅊ → ㅋ → ㅌ → ㅍ → ㅎ` 구현 |
| 모음 | `VOWELS` | 기본 자모 자체는 구현됨. 교육 순서는 `ㅏ → ㅑ → ㅓ → ㅕ → ㅗ → ㅛ → ㅜ → ㅠ → ㅡ → ㅣ`, `ㅐ`는 이후 복잡한 모음 단계로 재배치 예정 |
| 글자의 짜임 | `SYLLABLE_STRUCTURE` | 이미 배운 자모로 `가 → 나 → 다` 구현 |
| 받침 없는 글자 | `OPEN_SYLLABLES` | `ㅏ` 결합 글자는 구현됐지만 교육 순서를 초성 고정 기본 모음 행으로 재구성하고 `ㄱ` 행부터 확장 예정 |
| 받침 있는 글자 | `FINAL_CONSONANTS` | `각·간·갇·갈·감·갑` 구현. 기본 모음 행과 선택 메뉴를 먼저 완료한 뒤 다음 받침으로 확장 |
| 겹받침 | `DOUBLE_FINAL_CONSONANTS` | 마지막 단계 후보 |

코드의 `KoreanCurriculum.educationFlow`도 위 단계 순서를 고정한다. 현재 다음 제품 순서는 ① `가나다` 뒤 초성 고정 기본 모음 행 ② 교육 단계·글자 선택 메뉴 ③ 복잡한 모음 ④ 받침 있는 글자 추가 확장이다.

다음 단계는 현재 묶음의 자동 검증뿐 아니라 실제 관찰 기록에서 막힘이 없는지 확인한 뒤 결정한다. 무리한 반복이나 이미 통과한 화면의 근거 재수집은 새 학습 진전으로 간주하지 않는다.
