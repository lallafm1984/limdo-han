# 시각 아틀라스 자동 루프 기획

## 목적

다섯 살 아이가 글을 읽지 않아도 성공·실패와 홈·지우기·다음 동작을 그림과 짧은 움직임으로 구분하도록 한다. 시각 자산은 외부 이미지 API나 수동 문자 기호에 의존하지 않고 코덱스 내부 이미지 생성기로 만든 투명 PNG를 사용한다.

## 자동 역할

- 디자인 역할: 둥근 형태, 선명한 색, 같은 그림체, 작은 화면에서도 구분되는 실루엣을 판정한다.
- 연출 역할: 1.5초 이하의 유한한 움직임, 글자 길·현재 획·시작점·조작 비가림을 판정한다.
- QA 역할: 파일 규격, 자동 검사, 정확한 2340 × 1080 에뮬레이터 시작·중간·끝 화면과 실제 플레이 동작을 독립적으로 판정한다.
- 아이 대리 역할: 글을 읽지 못하지만 한국어를 들을 수 있는 다섯 살 아이 관점에서 다음 행동을 모양·위치·움직임만으로 구분할 수 있는지 점검한다. 실제 아이 관찰을 하지 않았다면 사람 팀 승인이나 실제 아이 통과로 표현하지 않는다.

## 단계

1. 루프 172: 성공 별빛·색종이 투명 아틀라스 적용과 비가림 검증
2. 다음 루프: 실패·다시 시도 투명 아틀라스 적용과 성공 상태 구분 검증
3. 다음 루프: 홈·지우기·다음 버튼 그림과 사용 가능·불가능 상태 개선
4. 최종 루프: 세 메뉴와 쓰기 전체 흐름의 디자인·연출·QA·아이 대리 통합 관문

각 단계가 통과하지 못하면 같은 실패 원인에 대한 최소 수정과 새 화면 근거를 한 번 더 만든다. 통과한 자산을 근거 없이 다시 생성하거나 같은 화면의 캡처 횟수만 늘리지 않는다.

## 루프 172 생성 자산 계약

- 생성 방식: 코덱스 내부 이미지 생성기

- 앱 적용 파일: `app/src/main/res/drawable-nodpi/limdo_success_feedback_atlas.png`
- 형식: RGBA PNG, 1774 × 887 px
- 배치: 2열 × 1행, 셀당 887 × 887 px
- 슬롯 0 `(0, 0, 887, 887)`: 노란 둥근 성공 별빛과 청록 중심 반짝임
- 슬롯 1 `(887, 0, 887, 887)`: 주황·노랑·청록 색종이와 작은 반짝임
- 표시 규칙: 두 축을 서로 다르게 늘이지 않고 정사각형 셀을 균일 배율로 축소한다. 성공 표식 전체는 140 × 104 dp 안에 두고 글자 길 바깥의 기존 성공 위치를 유지한다.
