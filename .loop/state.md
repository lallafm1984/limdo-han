# 현재 루프 상태

루프: 061 — 복원된 `IDLE`의 `INITIAL` 재생 중 프로세스 복원 탐색

상태: 준비

반복: 0

마지막 검증: 루프 060 반복 2의 독립 앱 데이터에서 소방차 `IDLE`을 `mHaveState=true`로 저장하고 PID `19172→19310`, `LaunchState: COLD`로 복원했다. 다시 듣기 `INITIAL` 시작·완료, 지우기 `준비 완료`, 첫 정상 입력 `SUCCESS` 시작·완료가 각각 1회였고 소방차는 `[99,62][435,288]→[225,62][561,288]`로 126 px 한 칸만 이동했다. `./scripts/verify.sh`, `git diff --check`가 통과했다.

완료한 조건: 루프 060 성공 조건 1~6 전체. 최종 아이 대리 QA를 통과했고 `실제 아이 관찰: 실행 안 함`이다.

현재 실패: 제품 실패 없음. 복원된 `IDLE`에서 다시 듣기 `INITIAL` 재생 중 다시 프로세스를 종료·복원하는 흐름은 새 근거로 검증하지 않았다.

현재 가설: 아직 세우지 않음. 다음 새 세션이 루프 061 반복 1의 반증 가능한 가설을 기록한다.

다음 작업: 제품 코드를 먼저 바꾸지 않고 소방차 `IDLE` 복원 뒤 `INITIAL` 재생 중 저장 Bundle과 두 번째 새 PID 복원, 음성 pending 및 첫 정상 입력을 독립 수집한다.

남은 조건: 루프 061 성공 조건 1~7 전체.
