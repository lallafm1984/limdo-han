# 현재 루프 상태

루프: 127 — 음성 재생 중 다시 듣기 상태 표시

상태: 준비

반복: 0

마지막 검증: 루프 126 반복 1에서 보상 `COMPLETE`와 `nextVehiclePending`을 함께 검사하는 `INITIAL` 재무장 관문을 추가했다. `./scripts/verify.sh`의 전체 단위 테스트·Android lint·debug build가 통과했다. 정확한 2340 × 1080에서 경찰차 3획 성공·3칸 이동→다음→소방차·빈 입력·`INITIAL` 시작·완료를 확인했고, 중복 다음은 추가 callback 0회였다. 안내 중 다시 듣기 후 지우기는 느지막 완료 callback 0회로 수렴했고, 소방차 재입력은 3획 성공·3칸 이동을 유지했다.

완료한 조건: 루프 126 성공 조건 1~7 전체. 루프 127은 아직 구현하지 않았다.

현재 실패: `INITIAL` 음성과 획별 시범이 실제 재생 중인데 다시 듣기 버튼은 빨간 금지선의 `🔇`로 보여 글을 읽지 못하는 아이에게 소리 끊김이나 고장으로 읽힐 수 있다.

현재 가설: `SpeechPlaybackState.Playing`을 단순 `available = false`와 분리해 소리 파동이 보이는 스피커 상태와 `재생 중` 접근성 설명을 주면, 중복 탭 비활성을 유지하면서 실제 사용 불가와 구분할 수 있다.

다음 작업: `ActionShelf`/`ReplayAction`이 정보 손실 없이 `SpeechPlaybackState`를 표현하도록 최소 상태 모델과 시각·semantics 회귀 테스트를 추가한다.

남은 조건: 루프 127 성공 조건 1~7 전체.
