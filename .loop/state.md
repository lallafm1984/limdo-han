# 현재 루프 상태

루프: 051 — 입력 전 첫 획 동적 시범

상태: 준비

반복: 0

마지막 검증: 루프 050 반복 1에서 물리 1080 × 2340, 앱 2340 × 1080, `user_rotation=1`의 초기·진행 중·재시도·성공 화면을 새로 수집했다. WritingCanvas 1962 × 775 px 안의 학습판은 620 × 620 px로 중앙 정렬되고 `ㄱ` 중심선 582.8 × 582.8 px, x/y 배율 1.0, guide 124 px를 유지했다. `./scripts/verify.sh`와 `git diff --check`가 통과했다.

완료한 조건: 루프 050 성공 조건 1~6 전체. 점선 학습판과 글자 transform이 같은 정사각형 em bounds를 사용하도록 최소 변경했고 정상 입력·재시도·성공·지우기·다시 듣기 동작을 유지했다. `아이 대리 점검: 조건부 통과`, `실제 아이 관찰: 실행 안 함`을 기록했다.

현재 실패: 입력 전 화면의 방향 화살표가 정지해 있어 시작→가로→꼭지→세로→끝 순서를 움직임으로 시범하지 않는다.

현재 가설: 입력 전 `ㄱ` 중심선을 따라 큰 안내 표식 하나를 반복 이동시키고 입력 시작 시 중단하면, 글을 읽지 못하는 아이에게 획 순서를 움직임으로 보여 주면서 기존 입력을 방해하지 않을 것이다.

다음 작업: 현재 정적 방향 표식과 상태 모델을 확인하고 입력 전 첫 획 시범만 추가하는 최소 애니메이션 변경과 테스트를 적용한다.
