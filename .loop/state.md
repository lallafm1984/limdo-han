# 현재 루프 상태

루프: 125 — 성공 뒤 아이가 이해할 수 있는 `다음` 진행

상태: 준비

반복: 0

마지막 검증: 루프 124 반복 4에서 재시도 cue 12종의 production 획 매핑 단위 테스트와 전체 68개 단위 테스트·lint·debug build를 통과했다. 정확한 2340 × 1080에서 2획 `RETRY_SECOND_FINISH`의 모든 범위가 `시범 획:2`, 3획 `RETRY_THIRD_FINISH`의 모든 범위가 `시범 획:3`이고 각각 완료된 뒤 null로 정리됨을 확인했다. 정상 3획 `SUCCESS` 시작·완료 1회, WritingCanvas 1962 × 775, 차량 3칸 최종 위치도 유지했다.

완료한 조건: 루프 124 성공 조건 1~7 전체. 루프 125는 아직 구현하지 않았다.

현재 실패: 성공·3칸 보상 완료 뒤에도 `다음`이 회색 `준비 중` 비활성으로 남고, 아이가 다음 쓰기와 차량으로 진행하려면 의미가 다른 `지우기`를 눌러야 한다.

현재 가설: 성공과 보상 완료를 `다음` 활성 조건으로 쓰고 차량 전진을 `onClear`에서 `onNext`로 옮기면, 아이가 활성 모양으로 다음 입력을 시작하면서 `지우기`는 현재 차량을 유지할 것이다.

다음 작업: `ActionPlaceholder`, `ActionShelf`, `VehicleCarouselState.prepareNextInput`, `onClear` 상태 전이를 조사하고 성공 완료 뒤 활성 `다음`과 현재 차량 유지 `지우기`를 최소 변경으로 분리한다.

남은 조건: 루프 125 성공 조건 1~7 전체.
