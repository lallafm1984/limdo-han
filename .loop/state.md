# 현재 루프 상태

루프: 184 — 보호자 전용 길게 누르기 진입과 lesson 목록
상태: 준비
반복: 0

단계: 그래픽·시스템 구현
시각 변경: 예
자산 필요 판정: 불필요 — 보호자 진입은 홈 카드와 분리된 단순 도형·텍스트·기존 디자인 token으로 명확히 만들 수 있고, 이번 범위에는 녹음 상태를 구분할 전용 bitmap이 아직 필요하지 않다.
전환 근거: 루프 183에서 선택·쓰기 HOME 그림체를 통일했고 새 P0·P1·진행 방해 P2가 없다. 2차 M1의 가장 앞선 미구현 제품 작업은 홈의 보호자 전용 2초 길게 누르기 진입과 현재 38개 lesson 목록 화면이다.
다음 작업: 새 세션은 홈 변경 전 화면을 먼저 수집하고, 아이의 일반 탭과 분리된 보호자 진입·닫기·38개 lesson 목록까지만 구현해 실제 2340 × 1080에서 검증한다. 녹음·권한·파일 저장은 후속 루프로 남긴다.
실제 아이 관찰: 실행 안 함. 자동·에뮬레이터·아이 대리 QA와 구분한다.
