# 현재 루프 상태

루프: 185 — 한 lesson의 쓰기 전 보호자 녹음
상태: 준비
반복: 0

단계: 그래픽·시스템 구현
시각 변경: 예
자산 필요 판정: 불필요 — 녹음·재생·삭제 상태는 기존 카드·색 token과 단순 Canvas 상태 도형으로 구분할 수 있고 새 bitmap은 권한·녹음 lifecycle을 더 명확하게 하지 않는다.
전환 근거: 루프 184의 보호자 2초 진입·38개 목록·안전한 복귀가 통과했고 새 P0·P1·진행 방해 P2가 없다. M1의 다음 미구현 제품 작업은 대표 lesson 하나의 `쓰기 전` 녹음 lifecycle과 app-private no-backup 저장이다.
다음 작업: 새 세션은 보호자 목록의 대표 lesson 한 개만 녹음 상세로 연결하고, 권한 요청·최대 8초·원자적 저장·미리 듣기·다시 녹음·삭제·이탈 해제를 실제 기기와 2340 × 1080에서 검증한다. 정답 후 녹음·전체 lesson 확장·아이 화면 재생은 후속 루프로 남긴다.
실제 아이 관찰: 실행 안 함. 자동·에뮬레이터·실제 기기·아이 대리 QA와 구분한다.
