# 현재 루프 상태

루프: 126 — `다음` 입력의 한국어 안내 재시작

상태: 준비

반복: 0

마지막 검증: 루프 125 반복 1에서 `VehicleCarouselState`의 다음 진행과 현재 차량 유지 지우기를 분리하고, 전체 단위 테스트·Android lint·debug build를 통과했다. 정확한 2340 × 1080에서 `다음`은 초기·보상 이동 중 `사용 불가`, 완료 뒤 `사용 가능`, 한 번 누른 뒤 다시 `사용 불가`였고 경찰차가 소방차로 한 단계 바뀌었다. 성공 뒤 지우기는 소방차를 유지했다.

완료한 조건: 루프 125 성공 조건 1~7 전체. 루프 126은 아직 구현하지 않았다.

현재 실패: `다음`으로 새 차량·빈 입력·동적 시범은 준비되지만 첫 앱 시작에 묶인 `INITIAL` 한국어 획순 안내는 자동 재생되지 않는다.

현재 가설: `onNext`가 기존 최신 요청 우선 음성 상태를 통해 `INITIAL`을 한 번 요청하면 이전 성공 callback과 충돌하지 않고 새 쓰기 안내를 재개할 수 있다.

다음 작업: `initialSpeechRequested`, `initialSpeechPending`, `onNext` 상태 전이를 조사하고 `INITIAL` 요청을 한 번만 재무장하는 최소 변경을 검증한다.

남은 조건: 루프 126 성공 조건 1~7 전체.
