# 현재 루프 상태

루프: 171 — 기본 모음 노출·순환·획순 교정
상태: 완료
반복: 1

사용자 근거: 모음이 나오는 순서와 실제 쓰는 순서가 다른 항목이 있다는 최신 실사용 지시가 들어왔다.
현재 근거: 기본 모음 메뉴와 다음 순환을 `ㅏ·ㅑ·ㅓ·ㅕ·ㅗ·ㅛ·ㅜ·ㅠ·ㅡ·ㅣ`로 고정했다. `ㅓ·ㅕ·ㅗ·ㅛ`의 production 획순·방향을 첨부표대로 교정했고 표시·점선·동적 표식·판정이 같은 geometry를 사용한다.
검증 결과: 101개 단위 테스트, 전체 verify·lint·debug build·diff 검사와 정확한 2340 × 1080 선택·대표 획별·`ㅣ → ㅏ → ㅑ` 화면 및 focus·치명 오류 관문이 통과했다.
우선 작업: 없음. 루프 171을 완료했고 활성 큐를 `없음`으로 바꿔 `IDLE` 종료한다.
실제 아이 관찰: 실행 안 함. 사용자 실사용 의견과 자동·에뮬레이터·아이 대리 QA를 구분한다.
