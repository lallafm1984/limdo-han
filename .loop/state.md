# 현재 루프 상태

루프: 128 — 현재 획만 강조하는 방향 안내

상태: 준비

반복: 0

마지막 검증: 루프 127 반복 2에서 새 APK의 정확한 2340 × 1080 정상 `가` 3획→경찰차 3칸→다음 소방차 `INITIAL`을 확인했다. 재생 중 중복 다시 듣기는 추가 시작 0회였고 지우기 뒤 9초 동안 느지막 획·완료 callback 0회였다. `./scripts/verify.sh`, `./scripts/check-automation.sh`, `git diff --check`가 통과했다.

완료한 조건: 루프 127 성공 조건 1~7 전체. 루프 128은 아직 구현하지 않았다.

현재 실패: 빈 `가` 화면에 현재 1획뿐 아니라 2·3획까지 네 방향 화살표가 모두 같은 강도로 보여, 글을 읽지 못하는 아이가 지금 따라갈 방향 하나를 고르기 어렵다.

현재 가설: 현재 `completedStrokes`와 입력 진행 상태에서 활성 획·선분을 파생해 그 방향 하나만 강조하면 production geometry와 판정을 바꾸지 않고 시각 경쟁을 줄일 수 있다.

다음 작업: `WritingCanvas`의 정적·동적 화살표 렌더링을 조사하고 입력 전·획 전환별 현재 방향 하나만 강조하는 최소 상태를 연결한다.

남은 조건: 루프 128 성공 조건 1~7 전체.
