상태: 준비

반복: 0

마지막 검증: 루프 128 반복 2에서 새 APK의 정확한 2340 × 1080 입력 전→1획→2획→3획 화면을 확인했다. 현재 획 방향 하나만 전환됐고 정상 `가` 3획 뒤 경찰차 3칸·다음 소방차·새 `INITIAL`이 유지됐다. `./scripts/verify.sh`의 72개 단위 테스트·Android lint·debug build와 `git diff --check`가 통과했다.

완료한 조건: 루프 128 성공 조건 1~7 전체. 루프 129는 아직 구현하지 않았다.

현재 실패: 1·2획 완료 뒤에도 큰 초록 시작점이 완료한 1획 시작 위치에 남아 현재 2·3획의 작은 움직이는 안내와 경쟁한다.

현재 가설: `completedStrokes.size`로 production `ga`의 현재 획 시작점을 선택하면 방향 안내와 같은 획을 가리키면서 판정 geometry를 유지할 수 있다.

다음 작업: `WritingCanvas`의 고정 시작점 렌더링을 조사하고 현재 획 시작점 하나만 강조하는 최소 상태를 연결한다.
