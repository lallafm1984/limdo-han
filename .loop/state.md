# 현재 루프 상태

루프: 196 — 성공 후 현재 메뉴 자동 다음
상태: 준비
반복: 0

단계: 그래픽·시스템 구현
시각 변경: 예
시각 변경 근거: 성공 전체 화면의 유지 시간과 다음 lesson 전환 상태가 바뀐다.
자산 필요 판정: 불필요 — 기존 성공 overlay·녹음 player·navigation을 재사용하며 새 bitmap은 자동 전환의 이해나 안전성을 높이지 않는다.
현재 판정: 루프 195가 자동·에뮬레이터·아이 대리 QA를 통과해 완료됐고 최신 미완료 사용자 지시의 다음 단일 동작으로 준비됨.
다음 작업: 성공 후 단일 녹음이 있으면 1회 재생 완료 뒤, 없거나 재생 실패면 기존 성공 연출의 최소 노출 뒤 현재 메뉴의 다음 lesson으로 정확히 한 번 이동하는 상태 계약을 먼저 확인한다. 홈·다시쓰기·이전·다음은 예약 이동과 재생을 취소해야 한다.
실제 아이 관찰: 실행 안 함. 자동·에뮬레이터·아이 대리 QA와 구분한다.
