# 현재 루프 상태

루프: 050 — 정사각형 학습판과 geometry 실측

상태: 준비

반복: 0

마지막 검증: 루프 049 반복 1에서 물리 1080 × 2340, 앱 2340 × 1080, `user_rotation=1`의 한 세션에서 첫 세 성공 시작 직후 지우기, 네 번째 성공 완료 뒤 지우기를 거친 직후 다섯 번째 정상 입력이 `SUCCESS` 시작→완료 한 회로 회복했고 4초 이상 유지됐다. `./scripts/verify.sh`와 `git diff --check`가 통과했다.

완료한 조건: 루프 049 성공 조건 1~8 전체. 제품 코드는 바꾸지 않았고 Canvas 1962 × 775 px, 버튼 373 × 168 px와 간격 37 px를 유지했으며 `아이 대리 점검: 통과`, `실제 아이 관찰: 실행 안 함`을 기록했다.

현재 실패: 최신 사용자 지시의 보이는 점선 중심축·학습판이 정사각형인지, 이것이 `ㄱ` template·표시·판정과 같은 정사각형 em에서 파생되는지 새 근거로 확인하지 않았다.

현재 가설: 전체 WritingCanvas의 크기를 유지하고 Canvas의 짧은 변에 맞춰 보이는 학습판을 정사각형으로 중앙 정렬하면, `ㄱ` 표시·판정의 균일 em과 기존 입력·음성 동작을 유지하면서 시각적 학습판만 정사각형으로 보정할 수 있을 것이다.

다음 작업: 현재 WritingCanvas·점선 학습판·`WritingCanvasGeometry`의 bounds와 배율을 먼저 실측하고, 보이는 학습판을 정사각형으로 만드는 최소 변경과 테스트를 적용한다.

남은 조건: 루프 050 성공 조건 1~6 전체.
