# 현재 루프 상태

루프: 192 — 입력 중 방향 화살표 손가락 가림 방지
상태: 준비
반복: 0

단계: 그래픽·시스템 구현
시각 변경: 예
자산 필요 판정: 불필요 — 기존 입력 중 vector 화살표의 공통 배치 계산 교정으로 해결할 결함이며 새 bitmap은 진행 방향을 더 명확하게 하지 않는다.
전환 근거: 루프 191의 `카` 가운데 가로획 연결이 자동·에뮬레이터·아이 대리 QA를 통과했고, 최신 사용자 지적의 손가락 가림 결함이 가장 우선인 미해결 제품 결함이다.
현재 판정: 준비 — 루프 191 완료 커밋·일반 push 후 다음 새 세션에서 긴·짧은 획의 변경 전 입력 중 화살표 거리를 먼저 수치화한다.
다음 작업: `inputDirectionGuide`의 마지막 입력점—화살표 중심 거리를 대표 획별로 측정하고 공통 최소 가시 거리와 짧은 잔여 구간 옆 배치를 하나의 검사 가능한 계산으로 세운다.
실제 아이 관찰: 실행 안 함. 자동·에뮬레이터·아이 대리 QA와 구분한다.
