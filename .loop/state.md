# 현재 루프 상태

루프: 205 — 자음+모음 조립 첫 좁은 묶음
상태: 준비
반복: 0

단계: 그래픽·시스템 구현
시각 변경: 예
시각 변경 근거: 아이가 자음과 모음 조각을 네모 칸에 놓아 음절 구조를 이해하는 새 사용자 화면과 상호작용이 필요하다.
자산 필요 판정: 불필요 — 첫 반복은 기존 production 글자 geometry·색·카드·모서리·그림자 token과 코드 도형으로 조립 위치·순서를 명확히 할 수 있는지 먼저 검증한다. 전용 bitmap은 교육 과제나 다음 행동을 더 명확하게 한다는 실화면 근거가 생길 때만 후속 판정한다.
현재 판정: 루프 204는 동일 최종 APK의 자동·on-device·TalkBack·큰 글자·움직임 줄이기·아이 대리 QA를 통과해 완료했다. M4 교육 확장의 첫 제품 작업을 준비했다.
다음 작업: `가·거·고·구·그·기` 전체를 한꺼번에 구현하지 말고, 자음 `ㄱ`과 세로 모음 `ㅏ`를 조립해 `가`가 되는 한 화면·한 상호작용의 geometry·위치·다음 행동부터 가설을 세워 최소 구현한다.
실제 아이 관찰: 실행 안 함. 자동·에뮬레이터·아이 대리 QA와 구분한다.
