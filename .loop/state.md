# 현재 루프 상태

루프: 199 — 보호자 자유 학습 목록 순서 변경·삭제
상태: 준비
반복: 0

단계: 그래픽·시스템 구현
시각 변경: 예
시각 변경 근거: 현재 보호자 화면은 lesson 추가와 총개수만 보여 주며, 추가된 항목 자체를 보거나 순서를 바꾸고 삭제하는 편집 화면·상태가 없다.
자산 필요 판정: 불필요 — 기존 production 카드·분류 token과 명시적인 위·아래·삭제 동작으로 보호자 편집을 구분할 수 있으며 새 bitmap이 순서나 삭제 의미를 더 안전하게 만들지 않는다.
현재 판정: 루프 198의 38개 allowlist·중복 추가·원자 저장·강제 종료 재실행 복원과 보호자 모드 분리, 기존 녹음 callback이 자동·에뮬레이터·실화면에서 통과했다.
다음 작업: 저장된 목록 항목을 순서대로 전부 보여 주고 각 항목을 한 칸 위·아래로 이동하거나 하나만 삭제하며, 중복 항목의 index를 혼동하지 않고 변경 순서를 원자 저장·재실행 복원하는 최소 편집 UI의 가설을 세운다.
실제 아이 관찰: 실행 안 함. 자동·에뮬레이터·아이 대리 QA와 구분한다.
