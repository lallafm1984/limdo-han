# 아이 대리 QA 발견 기록

이 문서는 정확한 2340 × 1080 에뮬레이터 화면과 동작 근거에서 발견한 아이 사용성 불편을 한글로 기록한다. 대상 아이는 한국어를 들을 수 있지만 한글 문장을 읽지 못한다고 가정한다. 이 기록은 `실제 아이 관찰`이 아니다.

## QA-001 — 안내 카드와 쓰기판의 시작점 색 불일치

- 상태: 루프 006의 전체 시각 재구성에 포함
- 우선순위: 높음
- 발견일: 2026-08-24
- 근거: 새 앱 데이터의 2340 × 1080 초기·재시도 화면에서 안내 카드의 점은 진한 초록색이고 쓰기판 시작점은 주황색이다.
- 아이 영향: 문구의 `주황 점`을 읽지 못하는 아이는 두 점을 같은 시작 위치로 연결하기 어렵다.
- 제안 수정: 시작점을 원본 안내 캐릭터와 같은 위치에 두고 색, 원형 모양, 진행 방향 단서를 한 화면 중앙에서 직접 연결한다.
- 연결 루프: 006
- 실제 아이 관찰: 실행 안 함

## QA-002 — 읽을 수 없는 문구와 카드가 쓰기 과제와 경쟁

- 상태: 루프 006에서 작업 예정
- 우선순위: 높음
- 발견일: 2026-08-24
- 근거: `captures/qa-loop006/01-start.png`, `02-retry.png`, `03-success.png`에서 상단 문장, 왼쪽 상태 카드, 하단 세 버튼이 화면을 나누고 실제 쓰기판 높이는 438 px에 머문다.
- 아이 영향: 글을 읽지 못하는 아이에게는 여러 문구와 카드보다 어디서 어떻게 쓰는지를 보여 주는 중앙 시범이 더 중요하다.
- 제안 수정: 참고 화면처럼 중앙의 큰 `ㄱ` 쓰기 길과 캐릭터 시범을 가장 강한 요소로 만들고, 음성·지우기 등 필수 조작만 큰 아이콘으로 남긴다.
- 연결 루프: 006
- 실제 아이 관찰: 실행 안 함

## QA-003 — 넓은 Canvas 안에서 실제 글자 길은 좁음

- 상태: 루프 006에서 최우선 작업 예정
- 우선순위: 매우 높음
- 발견일: 2026-08-24
- 근거: 반복 2 화면에서 WritingCanvas는 1962 × 775 px로 넓지만 `WritingCanvasGeometry`가 짧은 변 기준 정사각형을 만들어 실제 `ㄱ` 가로 획은 약 496 px에 머문다.
- 아이 영향: 빈 공간은 넓어도 실제로 따라 쓰고 판정받는 경로가 화면 중앙에 작아 손가락을 크게 움직여 쓰기 어렵다.
- 제안 수정: 실제 `ㄱ` 가로 획을 최소 1170 px, 세로 획을 최소 540 px로 확대하고 보이는 경로와 판정 geometry를 하나로 유지한다.
- 연결 루프: 006
- 실제 아이 관찰: 실행 안 함

## 현재 감사에서 확인한 강점

- 기존 쓰기판은 최소 크기 기준을 넘고 손가락 입력과 판정이 작동한다.
- 초기·재시도·성공 음성 callback과 큰 다시 듣기·지우기 버튼이 작동한다.
- 비활성 다음 버튼은 시각적으로 약하다.

## 근거 한계

- 화면과 UI hierarchy 및 음성 callback을 성인이 아이 관점으로 점검했다.
- 실제 아이가 시작점을 찾거나 음성을 이해하는지 관찰하지 않았다.

## QA-004 — 초기 안내 재생 중 다시 듣기 상태 전환 미검증

- 상태: 루프 007 QA 탐색 예정
- 우선순위: 보통
- 발견일: 2026-08-24
- 근거: `captures/loop006/iteration7/initial.png`은 자동 초기 안내가 재생되는 동안 다시 듣기가 회색·음소거 아이콘으로 잠시 비활성인 상태를 보여 준다. 이후 재생 완료 시 활성 상태로 바뀌지만 그 시각 전환을 새 연속 화면으로 점검하지 않았다.
- 아이 영향: 문구를 읽지 못하는 아이가 안내 중인 비활성 버튼과 안내 완료 후 누를 수 있는 버튼을 자연스럽게 구분하는지 아직 알 수 없다.
- 제안 수정: cold launch 직후부터 음성 완료 후까지 화면·hierarchy·callback을 연속 수집해 실제 불편인지 판정하고, 입증된 문제가 있을 때만 최소 수정한다.
- 연결 루프: 007
- 실제 아이 관찰: 실행 안 함
