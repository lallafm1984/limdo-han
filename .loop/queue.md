큐 규칙:

- `활성` 루프는 정확히 하나만 존재할 수 있다.
- Codex 앱에서 받은 최신 미완료 사용자 수정 지시를 현재 루프 범위에 우선 반영한다.
- 완료 직전 새 아이 대리 QA에서 근거가 있는 가장 중요한 미해결 불편 하나만 다음 번호 루프로 만든다.
- 새 불편이 없으면 최신 사용자 지시와 장기 한글 학습 목표의 미완료 제품 작업 하나로 전환한다.
- 같은 검증에서 숫자만 늘린 반복과 `N+1`회 재수집은 준비하거나 활성화하지 않는다.
- 새 불편, 서로 다른 사용자 위험, 미완료 제품 작업이 모두 없으면 활성 루프를 `없음`으로 만들고 종료한다.
- 같은 작업자는 다음 루프를 준비만 하고 구현은 다음 새 세션에 맡긴다.
- 큐 전환은 `.loop/history.md`와 `.loop/qa-findings.md`에 한글로 기록한다.
- 실제 아이가 사용하지 않았다면 아이 대리 QA를 실제 아이 관찰로 표현하지 않는다.
- 루프 154 뒤에는 `docs/1차-목표-작업-기획서.md`의 순서대로 `자음·모음·가나다` 세 메뉴 기능 → 통일 디자인 → 안전한 화려한 연출 → 자동 QA 역할 → 다섯 살 아이 대리 시뮬레이션을 이어 간다.
- 1차 목표 완료 관문이 모두 통과하기 전에는 새 불편이 없다는 이유로 큐를 비우지 않는다. 모두 통과하면 큐를 `없음`으로 만들고 `IDLE`로 종료하며 2차 목표는 자동 시작하지 않는다.
