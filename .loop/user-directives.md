# Codex 앱 사용자 수정 지시

이 문서는 사용자가 Codex 앱에서 전달한 최신 제품 수정 지시를 새 CLI 세션에 인계한다. 최신 미완료 지시가 현재 루프 범위 안에서 가장 높은 우선순위다. 지시를 반영한 뒤에도 기존 검증, 로컬 우선, 안전 경계와 실제 아이 관찰 근거 구분을 유지한다.

## 2026-08-24 — 어린이 학습 화면 시각 방향

- 상태: 활성
- 사용자 지시: `design/reference-kids-tracing-ui.png` 같은 UI·UX로 아이들이 쉽게 학습할 수 있는 화면을 만든다.
- 적용 화면: 현재 `ㄱ` 따라 쓰기 핵심 화면.
- 반드시 유지: 정확한 손글씨 입력과 판정, 한국어 음성 안내와 다시 듣기, 지우기, 오프라인 동작, 2340 × 1080 기준, 큰 실제 입력 영역.
- 시각 기준: 밝고 따뜻한 노란 배경, 장식은 낮은 대비, 화면 중앙의 아주 큰 흰색 `ㄱ` 쓰기 길, 시작점의 독창적인 동물 안내 캐릭터, 끝점 목표, 가장자리의 크고 단순한 조작 버튼, 최소한의 읽기 의존성.
- 원본 자산: `app/src/main/res/drawable-nodpi/limdo_gecko_guide.png`, `limdo_sunny_flower_background.png`를 사용한다. 참고 화면의 캐릭터와 장식을 직접 복사하지 않는다.
- 접근성: 글을 읽지 않아도 시작점, 진행 방향, 성공·재시도, 다시 듣기, 지우기, 비활성 동작을 알 수 있어야 한다. 보호자와 접근성 서비스를 위한 짧은 한글 설명은 유지한다.
- 범위 제한: 이번 루프에서 새 글자, 새 수업, 저장, 점수, 보상, 서버, 로그인, 분석, 광고, 민감 권한을 추가하지 않는다.
- 전달 방식: 앞으로 새 수정 지시는 Codex 앱에서 전달하며 앱 작업자가 이 문서와 현재 루프 목표에 한글로 반영한다.

## 참고 이미지의 역할과 제한

- 참고 이미지는 밝은 색감, 중앙 집중형 쓰기 과제, 캐릭터가 획 방향을 보여 주는 구조와 큰 가장자리 버튼의 시각 기준이다.
- 참고 이미지의 상표, 로고, 정확한 캐릭터, 과일 그림, 배치를 그대로 복제하지 않는다.
- 실제 Android 구현은 LimDo의 기존 기능과 접근성 계약에 맞게 재구성한다.

## 2026-08-24 — 실제 글자 쓰기 폭 확대

- 상태: 활성, 이전 시각 방향보다 우선
- 사용자 지시: 입력 넓이가 아이들에게 너무 좁으므로 참고 이미지처럼 넓게 만들어 쉽게 글자를 쓰게 한다.
- 측정 기준: 2340 × 1080에서 실제 손가락 입력 내부는 최소 1872 × 648 px이다.
- 핵심 보정: 빈 Canvas만 넓히지 않는다. 실제 보이는 동시에 판정에 사용하는 `ㄱ` 가로 획은 최소 1170 px, 세로 획은 최소 540 px로 확대한다.
- 구현 경계: 화면에 보이는 목표 길과 `GieokTraceEvaluator`가 판정하는 경로는 같은 geometry를 사용해야 한다.
- 배치: 다시 듣기, 지우기, 비활성 다음 동작은 쓰기 길을 침범하지 않도록 가장자리 또는 하단 안전 영역에 둔다.
- 검증: 새 APK의 초기·재시도·성공 화면에서 입력 내부 bounds와 목표 가로·세로 획을 각각 실측한다.
